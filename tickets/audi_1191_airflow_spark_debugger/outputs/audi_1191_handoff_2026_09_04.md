## Standing gotchas

- **Astro superseded-build gap.** Back-to-back merges cancel each other's build and a merge SHA can
  register no build at all. Wait for DEPLOYED between merges. The GitHub "Deploy to Prod" action only
  syncs GCS files and never rebuilds the image.
- **PR numbers, AUDI numbers and worktree names are all offset** in the hackathon batch — PR #1273 is
  AUDI-1269 on branch `audi-1269-shuffle-partitions-preverified`. Always resolve the branch with
  `gh pr view <N> --json headRefName`. Getting this wrong merged main into an already-merged branch.
- **The gauntlet hook parses `cd <literal path>` from the command.** A shell variable in the `cd` makes
  it fall back to the workspace repo and block the PR. Use the literal path in the same command.
- **main's spark-optimizer CI can be red on its own.** It was on 09-03: a stale gsutil-era mock in
  `test_newest_logs` after #1264 moved fetch to the GCS JSON API, plus five missing return annotations.
