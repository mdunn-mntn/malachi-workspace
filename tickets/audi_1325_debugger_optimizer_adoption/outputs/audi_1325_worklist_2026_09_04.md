## Standing gotchas that shape the work

- **Astro superseded-build gap.** Back-to-back merges cancel each other's build and a merge SHA can register no build at all. Wait for DEPLOYED between merges. The GitHub "Deploy to Prod" action only syncs GCS files and never rebuilds the image.
- **PR numbers, AUDI numbers and worktree names are offset** in the hackathon batch. Always resolve the branch with `gh pr view <N> --json headRefName`.
- **The gauntlet hook parses `cd <literal path>`** from the command; a shell variable in the `cd` makes it fall back to the workspace repo and block the PR.
- **main's spark-optimizer CI can be red on its own**, as it was on 09-03.
