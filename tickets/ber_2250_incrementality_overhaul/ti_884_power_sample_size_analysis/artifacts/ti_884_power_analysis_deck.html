Appendix — Methodology

How "power" is calculated, from first principles.

Full walkthrough in artifacts/ti_884_methodology.md

Step 1 — What "power" actually is.

Every experiment is a hypothesis test. Two ways to be wrong:

Truth: H₀ (no lift)Truth: H₁ (real lift δ)
Decide H₁Type I error · prob = αCorrect · prob = 1 − β = power
Decide H₀CorrectType II error · prob = β
  • α = 0.05 — false-positive tolerance (we pick this up front)
  • 1 − β ≥ 0.80 — desired power (we pick this up front)
  • MDE = smallest δ we have power to detect at chosen α and 1 − β

Step 2 — The two-proportion z-test.

For each arm, compute visit rate. The lift estimator:

Δ̂ = p̂t − p̂c

Each IP is a Bernoulli(p) draw → variance p(1−p). Sample mean of n IPs has variance p(1−p)/n. Two arms independent → variances add:

SE(Δ̂) = σ · √(1/nt + 1/nc), where σ = √(p(1−p))

Standardize: z = Δ̂ / SE. Under H₀, z ~ N(0,1). Reject H₀ if |z| > zα/2 = 1.96.

Step 3 — Inverting the test gives MDE.

Under H₁ (true effect = δ), require P(reject H₀) ≥ 1 − β. Plug in the normal CDF, solve for δ:

MDEabs = (zα/2 + z1−β) · σ · √(1/nt + 1/nc)

For α = 0.05 and power = 0.80:

  • zα/2 = z0.025 = 1.96
  • z1−β = z0.80 = 0.84
  • Sum = 2.80 — this is the constant in every Lewis-Rao calc

Stakeholders care about relative lift: MDErel = MDEabs / p.

Each technique replaces SE with SE × vr; they stack multiplicatively.

Why CVR is ~6× harder than visits — same math.

MDErel scales as σ/p. For binary outcomes, σ/p = √((1−p)/p) — drops as p rises.

Outcomep (cohort median)σσ / p
Visit rate2.15%0.1456.74

Same N, same advertiser, same variance reduction → CVR MDE is ~6× higher than visits MDE. Pure consequence of σ/p scaling. To halve CVR MDE, you need 4× the spend.

Caveats / where MDE numbers might be off.

  • CUPED ρ varies by advertiser (0.17 Vivint vs 0.46 WGU). Per-advertiser ρ should be measured before publishing TI-885 numbers.
  • Ghost-ad multiplier 0.75 is literature. TI-837 win-rate work could give MNTN-specific number.
  • Cohort-median spend curve is "typical advertiser." Use the per-advertiser table for actual decisions.
  • IPs aren't perfectly independent (households have multiple IPs). Bias is small because hash randomizes at IP level.
