What this means.

  • For Al's question: the budget threshold is two answers. $200k/month for visits; $2M+/month for conversions.
  • For TI-885 advertiser selection: recruit only from the 48-of-50 well-powered top advertisers. The MDE calculator gates enrollment.
  • For BER-2250 stakeholder communication: stop reporting "Lift %" without the matching MDE confidence band. Anything below MDE is noise — even when it looks clean.
  • Re-frame the conversation: incrementality measurement is a budget question, not a methodology question. Methodology is solved.

Methodology — what's behind the numbers.

  • Lewis & Rao (2015 QJE): N = 2 × ((zα/2 + zβ) · σ / Δ)². Outcome-agnostic — calculator handles binomial (visits, CVR) and continuous (iROAS).
  • CUPED ρ measured on MNTN data: mean 0.357 across 3 large advertisers. Range 0.17–0.46. SE multiplier: 0.934 (literature midpoint was 0.866 — MNTN is a bit weaker).
  • Ghost-ad conditioning (Johnson-Lewis-Reiley 2017): 25% SE reduction. TI-837's win-rate work supports this.
  • Holdout: 10% per-advertiser hash. Validated TI-837 phase 0c (2026-04-29).
  • Calculator: ti_884_mde_calculator.py. Sample sizing for any advertiser is one function call.
