Jason Huertas (TPM) owns plumbing + Bombora contacts; John Pankowski works the audience strategy with Bombora.

Bombora = vendor-neutral B2B intent **data supplier** (6Sense competitor). Moat = Data Co-op (~86% exclusive, consent-based, not bidstream) + Company Surge (account-level intent, 3wk vs 12wk baseline) + ~21.6K topic taxonomy + firmographic/persona resolution. Plugs into MNTN two ways: (1) custom segment via the **LiveRamp pipe** (join key = SegmentID, ~3-day lead time), (2) S2S impression enrichment → B2B reporting (platform whitelabel, lands ~July 2026). DS51 = legacy registration, 0 IPDSC volume.

**My angle (AUDI + incrementality owner):** Company Surge is an *in-market* signal → an intent-only audience risks the same demand-harvesting / ~0-incrementality problem found on ElevenLabs prospecting ([[project_incrementality_experiment]], TI-1044/TI-1061). White-glove design should balance net-new ABM accounts vs pure surge, and preserve a holdout so Bombora lift is provable.
