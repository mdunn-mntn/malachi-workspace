Rogus announced the Engineering Levels & Skills Rubric on 2026-04-06.

**Timeline:**
- **Within ~1 month (by ~May 2026):** Direct manager (Alyson) will translate current performance against old expectations into the new rubric language. This is the first feedback checkpoint.
- **~6 months after that (~November 2026):** Informal mid-point feedback cycle. If Alyson doesn't initiate, ask for it.
- **~1 year from now (~April 2027):** Next official review cycle.

**Why:** The rubric language is now more specific per-level. Current review feedback will be re-framed against the new criteria.

**How to apply:** When writing self-review entries, use the new per-level rubric language (integrated into `self_review/summary.md`). When Alyson gives the first translation feedback, update the self-review guide with any calibration insights — what level she maps current work to, which criteria need more evidence.
