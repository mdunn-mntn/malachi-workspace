**Q2 ceremony changes (Bryce Wagg, 2026-04-07):**

- **Weekly backlog grooming:** Bryce + Mike (possibly squad leads later). Reviews upcoming work, sets sprint priorities, adjusts acceptance criteria/descriptions/timelines before sprint begins.
- **Weekly project syncs:** Per active project. Align on risks, timelines, scope. Also used for demos and pair programming.
- **Standups:** Shorter and more tactical now that project syncs handle bigger picture. Focus: blockers, PR reviews, immediate attention items. Analogy: "calling out holes in the boat so we can all swarm."
- **Pre-meeting prep:** Update tickets before standup and planning meetings — spend meeting time on decisions, not data entry.

**Why:** Q2 kickoff established tighter sprint process aligned with PMO best practices. Separates tactical (standup) from strategic (project syncs).

**How to apply:** Keep Jira tickets current before ceremonies. Flag blockers in standup, save detailed project discussion for syncs.
