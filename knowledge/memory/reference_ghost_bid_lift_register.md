Matt Brorby's **ghost-bid lift bias register** is the most complete catalogue of native ghost-bid incrementality biases (A1–A8 assignment, B identity, C window, D estimator, E reporting, F causal-interp): `SteelHouse/databricks_targeting` → `exploration/INCR-first-ascent/ghost_bid_lift_bias_register.md` (branch `INCR`). Read before any ghost-bid lift analysis. Beeswax leg, interim; signed magnitude pending the MNTN fcap-symmetric leg (INCR-63).

**Dominant bias = `ghost_frac` BID-MULTIPLICITY selection, NOT fcap-asymmetry** (re-diagnosed 2026-06-23). Holdout IPs never win → never exit the prospecting pool → re-enter auctions → over-accumulate bids → inflate the distinct-IP holdout fraction (0.10→0.47 from 1→11+ bids) → manufacture a spurious NEGATIVE lift. **Fix: gate to clean `ghost_frac` (.09–.11)** → every prior "Beeswax negative" vanishes. (fcap is config-OFF for prospecting → nothing to reconstruct.) Also: use a **single first-bid 7d anchor** per IP, not `MAX()` over per-day windows (the MAX gave holdout a wider window → ~6.7pp fake negative).

**Persuadables gradient (population-wide, all advertisers, clean-gf, 2026-06-25):** incremental visit lift (rel) by band — High +0.2% (~0) · PP +1.6% · Mid +3.3% · MaxReach +3.4% · no_score +0.1% (~0). **Mid-intent (PP/Mid/MaxReach) carry the lift; top-intent (High) and untargeted reach (no_score) are incrementally dead.** no_score has a HIGHER baseline visit rate (0.96%) than PP (0.57%) = would-visit-anyway, not incremental (the "no_score looks good on raw visits but is dead incrementally" trap; WGU is 100% no_score). Saturation cut agrees: 21+ -cross-targeted IPs incrementally dead despite highest baseline. **Targeting: lean mid-intent × less-saturated; avoid top-intent / heavily-contested / reach.** Backs the perf-vs-incrementality opposition + TI-999/TI-956 mid-intent recs.

**Scale gotcha:** at 100M+ IPs z is 5–13 at ~0 magnitude (+0.001pp) = bias-floor, not power — read absolute pp + per-campaign FDR, never the pooled z. **MNTN bidder leg = clean reference** (writes ghost bids to fcap cache → holdout exits symmetrically); Beeswax has residual multiplicity bias. Verdict: pooled ≈0, clean-gf FDR has zero sig negatives + one-sided-positive tail → real effect non-negative (zero-to-positive). See [[project_incrementality_experiment]], [[feedback_no_naive_pre_post]]. Full extract: `knowledge/experimentation.md` §"Ghost-bid lift — bias register + the persuadables gradient".

**Queryable in BQ + the INCR-77 practical method (2026-07).** The lift is now exposed as SQLMesh views: silver `enriched.lift__ghost_bid_visits` (arms `ghost`=holdout / `submitted`=treatment; `visited`/`converted` over a **7-day-from-first-bid** window; grain dt×adv×cg×campaign×ip×arm) + `…lift__ghost_bid_audiences`; gold `reporting.lift__ghost_bid_results` (campaign×stratum) + `lift__ghost_bid_rollup` (advertiser/cg weighted: abs_itt/SE/CI/z/MH). **The QUERYABLE table is the BEESWAX/JVM leg** (source `bid_price_log`) — the MNTN Rust leg (`bidder_bid_events`, partner ~79) is NOT folded in yet, so "MNTN leg = clean reference" above is the *conceptual* clean leg, not what you query today. **Practical debias = entry-cohort anchor (`ROW_NUMBER() … PARTITION BY adv,campaign,ip ORDER BY dt`=1) + EXCLUDE the first window day** (left-censored stock → ghost_frac 0.12 → spurious negative); on the clean set ghost_frac→0.10 and pooled visit lift = **+5%** (z≈26). **Gold `ghost_bid_rollup`/`_results` are NOW time-boxed (AUDI-1148, 2026-07-22, Matt confirmed)** — one-liner `SELECT * FROM …lift__ghost_bid_rollup WHERE entity_id=<cg_id>` reproduces the windowed silver calc to the digit; `_results WHERE campaign_group_id=<id>` strata by `stratum_type` (overall/score_band/bid_count), score_band ∈ High/Mid/no_score (confirm intent-band composition). *(old "rollup reads −1.8%" superseded — was pre-time-boxing.)* Gotcha: an "excludes high intent" campaign can be ~100% no_score (High+Mid both excluded = the dead reach band, not mid-intent) → ~0 lift is EXPECTED, check `_results` score_band before assuming it lifts. See [[reference_mntn_campaign_stages]]. Tables now **accumulate (no TTL)** → a real ≥30-day window ~late-July. Two gotchas: a measured lift and a power MDE are different instruments (bid-grain ~10d vs served-grain future-8wk) — never compare magnitudes; and a confirmed *current* ghost-lift does NOT make an advertiser *testable* — **power (can we run a clean 5% test?) is the binding Top gate**, keep lift as a gate+display, not folded into the ranking score (INCR-77 tier = power×confirmed 2×2). Matt Brorby owns the lift-measurement pipeline; Ryan Kleck deployed the MNTN-bidder ghost-bid change (2026-05-27). Tables: `data_catalog.md` §"lift__ghost_bid_*".

**Holdout is FIXED ~10% platform-wide (AUDI-1148, 2026-07-22) — not a per-test tunable, no plans to change.** So "bigger holdout" is NOT a lever; power comes only from campaign SIZE or POOLING across advertisers/campaigns on the same audience. A small low-VR campaign can't resolve a few-percent lift alone: Gruns CGID 126905 (excludes high intent, 0.19% VR) → 10% holdout = ~19 holdout visits/3wk → +15% rel but 95% CI [-32%,+63%], p=0.53. **Single-campaign filter:** `enriched.lift__ghost_bid_visits` supports a `campaign_group_id` filter (entry-cohort, drop the left-censored first day; window ends 7d before data edge since `visited`=visit-within-7d-of-first-bid). Rule: to test "does audience X lift incrementality?", pool X across advertisers — don't wait on one campaign. Full detail: `experimentation.md` §"Ghost-bid lift".

**Refreshed 2026-07-24 (BER-2250/AUDI-789), + the Simpson trap.** On the wider gold window the gradient HOLDS: clean-gated IVW rel lift by band = Mid +9.2% · MaxReach +6.6% · PP +1.8% · High +1.7% · no_score +0.2% (~dead). **Cross-campaign band aggregation MUST use inverse-variance weights** (`SUM(abs_itt/se²)/SUM(1/se²)`), NOT a naive count pool (`SUM(vis)/SUM(n)`) — the naive pool reported no_score **+29%** (Simpson confound across ~985 heterogeneous campaigns); IVW puts it back at ~0. Clean gate on `reporting.lift__ghost_bid_results` = `has_valid_holdout AND meets_min_n AND meets_min_compliance AND NOT ghost_frac_inflated AND NOT arm_imbalance_suspect AND se>0`. **Raw-visit rank (High>no_score>PP>Mid>MaxReach) is ~inverted vs incremental-lift rank** → a visit/spend-optimized scorer (AUDI-789 WS1) de-optimizes incrementality.
