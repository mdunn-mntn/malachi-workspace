**Dominant bias = `ghost_frac` BID-MULTIPLICITY selection, NOT fcap-asymmetry** (re-diagnosed 2026-06-23). Holdout IPs never win → never exit the prospecting pool → re-enter auctions → over-accumulate bids → inflate the distinct-IP holdout fraction (0.10→0.47 from 1→11+ bids) → manufacture a spurious NEGATIVE lift. **Fix: gate to clean `ghost_frac` (.09–.11)** → every prior "Beeswax negative" vanishes. (fcap is config-OFF for prospecting → nothing to reconstruct.) Also: use a **single first-bid 7d anchor** per IP, not `MAX()` over per-day windows (the MAX gave holdout a wider window → ~6.7pp fake negative).

**Persuadables gradient (population-wide, all advertisers, clean-gf, 2026-06-25):** incremental visit lift (rel) by band — High +0.2% (~0) · PP +1.6% · Mid +3.3% · MaxReach +3.4% · no_score +0.1% (~0). **Mid-intent (PP/Mid/MaxReach) carry the lift; top-intent (High) and untargeted reach (no_score) are incrementally dead.** no_score has a HIGHER baseline visit rate (0.96%) than PP (0.57%) = would-visit-anyway, not incremental (the "no_score looks good on raw visits but is dead incrementally" trap; WGU is 100% no_score). Saturation cut agrees: 21+ -cross-targeted IPs incrementally dead despite highest baseline. **Targeting: lean mid-intent × less-saturated; avoid top-intent / heavily-contested / reach.** Backs the perf-vs-incrementality opposition + TI-999/TI-956 mid-intent recs.

**Scale gotcha:** at 100M+ IPs z is 5–13 at ~0 magnitude (+0.001pp) = bias-floor, not power — read absolute pp + per-campaign FDR, never the pooled z. **MNTN bidder leg = clean reference** (writes ghost bids to fcap cache → holdout exits symmetrically); Beeswax has residual multiplicity bias. Verdict: pooled ≈0, clean-gf FDR has zero sig negatives + one-sided-positive tail → real effect non-negative (zero-to-positive). See [[project_incrementality_experiment]], [[feedback_no_naive_pre_post]]. Full extract: `knowledge/experimentation.md` §"Ghost-bid lift — bias register + the persuadables gradient".
