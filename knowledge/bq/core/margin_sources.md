# core.margin_sources

## Purpose
Tiny enum lookup dimension that labels **where a channel-margin value came from** (its origin/source). Margin-config rows carry a `margin_source_id` FK back here so a reader can tell which source produced a given margin. Reach for it only to decode that FK into a human-readable `name`; it holds no margin/rate numbers itself.

Thin silver view (`SELECT *`) over the Datastream-CDC dimension `dw-main-bronze.integrationprod.core_margin_sources` (a plain physical TABLE, not SQLMesh-versioned).

## Grain & keys
- **Grain:** one row per margin source. Live count = **2 rows** (enum lookup).
- **Primary key:** `margin_source_id` (also the sole cluster key on the physical).
- **Referenced by (FK `margin_source_id`):** `core.campaign_group_channel_margins`, `core.select_margins` (+ the `core.v_campaign_group_channel_margins` view and the out-of-dataset `archives_campaign_group_channel_margin_archives` history table).
- **No `deleted` / `is_test` columns** exist on this dim, so the usual `deleted=FALSE AND is_test=FALSE` live-row filter does **not** apply here.

## Column meanings (only the non-obvious ones)
- **`margin_source_id`** — surrogate integer PK / cluster key. Small enum domain (2 members). Join target for `margin_source_id` FKs on the margin-config tables.
- **`name`** — human-readable label of the margin source category. (Sensitive-margin table: value strings not reproduced here per catalog policy — decode live if needed via the FK join.)
- **`datastream_metadata`** — Datastream CDC bookkeeping STRUCT, not business data.
  - `.uuid` — CDC change-record UUID for the last write of this row.
  - `.source_timestamp` — CDC **capture** epoch in **MILLISECONDS** (decode with `TIMESTAMP_MILLIS(...)`; e.g. `1766121497982` → 2025-12-19, matching the table's Dec-2025 creation). This is the replication capture time, **not** a business create/update time — and no business `create_time`/`update_time` columns exist on this dim, so there is no business-time signal to prefer over it.

## Joins & relationships
- **`core.campaign_group_channel_margins.margin_source_id` → this.margin_source_id** — N:1. This dim is the **1 (parent)** side; the config table is the **N (child)** side. Joining a config row → `margin_sources` is safe (N:1, no fan-out — just appends the source name). Joining `margin_sources` → the config table fans out to **many** config rows per source.
- **`core.select_margins.margin_source_id` → this.margin_source_id** — same N:1 shape (Select-product margin config on the N side).
- **`core.v_campaign_group_channel_margins`** — a view over the campaign-group channel-margin config; carries the same `margin_source_id` FK.
- All join directions from a config table into this dim are fan-out-safe; only the reverse (dim → config) multiplies rows.
