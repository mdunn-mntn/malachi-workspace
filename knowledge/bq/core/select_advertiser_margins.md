# core.select_advertiser_margins

## Purpose
Per-advertiser **MNTN Select** pricing overrides. Holds the three Select margin components
(`budget_margin`, `data_margin`, `platform_fee`) for advertisers whose Select economics deviate from the
platform default. It is the advertiser-scoped override layer that sits on top of the single global default
row in **`core.select_margins`** (which carries the same three columns plus `margin_source_id`, no
`advertiser_id`). Reach for it when you need an advertiser's Select take-rate composition; if an advertiser
has **no row here**, the `select_margins` default applies.

> **SENSITIVE — take rates are private.** Document schema/grain/keys only. Do **not** sample, print, or
> reproduce actual `budget_margin` / `data_margin` / `platform_fee` values or any row containing them.

## Grain & keys
- **Grain:** one row per advertiser-level Select margin override. Empirically **1 row total** (physical
  `numRows=1`) as of 2026-07-19 — this is a sparse override table, not a per-advertiser complete map.
- **Primary key:** `select_advertiser_margin_id` (the physical is clustered on it).
- **Join column:** `advertiser_id` → `core.advertisers.advertiser_id` (FK, N:1).
- **No `deleted` / `is_test` columns** on this table — the standard `deleted=FALSE AND is_test=FALSE`
  dimension hygiene filter does **not** apply here (neither column exists). Filter test/deleted advertisers
  on the joined `advertisers` dim instead.

## Column meanings (only the non-obvious ones)
- **`select_advertiser_margin_id`** — surrogate PK for the override row (not the advertiser id).
- **`advertiser_id`** — FK to `core.advertisers`. Identifies which advertiser this Select override applies to.
- **`budget_margin`, `data_margin`, `platform_fee`** — the three Select margin components, each stored as
  **`NUMERIC(5,4)`** — a fractional rate to 4 decimal places (schema precision 5 / scale 4, so magnitude
  < 10.0000; these are rate fractions, e.g. a 4-decimal proportion, not dollar amounts and not whole
  percents). **Values are SENSITIVE (take rates) — do not print them.** Together they decompose the Select
  take rate into a budget/media component, a data component, and a fixed platform fee.
- **`create_time`** — real `TIMESTAMP` (UTC); when the override row was first written.
- **`update_time`** — real `TIMESTAMP` (UTC); **NULL when the row has never been updated since insert**
  (the current single row has `update_time = NULL`). Do not assume non-null.
- **`datastream_metadata`** — Google Datastream CDC envelope (`STRUCT<uuid STRING, source_timestamp INT64>`).
  - `source_timestamp` is the **CDC capture epoch in MILLISECONDS** — verified: `1766121490229` →
    `TIMESTAMP_MILLIS` = 2025-12-19 (sensible, near table creation) while `TIMESTAMP_MICROS` = 1970
    (nonsense). It is replication-capture time, **not** business time — prefer `create_time` / `update_time`
    for business logic.
  - `uuid` is the Datastream change-event id, not a business key.

## Joins & relationships
- **`advertiser_id` → `core.advertisers.advertiser_id`** — partner grain: `advertisers` is 1 row per
  advertiser (PK `advertiser_id`). This direction is **N:1, fan-out safe** (each override references one
  advertiser). The reverse (`advertisers` LEFT JOIN this table) is **1:0-or-1** — almost every advertiser
  has **no** override row, so the joined margin columns come back NULL for nearly all advertisers; that NULL
  is the signal to fall back to the `select_margins` default. Filter `deleted=FALSE AND is_test=FALSE` on
  the `advertisers` side (those flags do not exist here).
- **`core.select_margins`** — the sibling **default** table (1 row, same three margin columns +
  `margin_source_id`, no `advertiser_id`). Conceptual relationship: `select_advertiser_margins` **overrides**
  the single global `select_margins` default per advertiser. There is no direct join key between the two;
  the resolution is coalesce-style (advertiser override if present, else global default).
- Related Select/PMP pricing context (per `data_knowledge.md`): `core.private_marketplace_deals` /
  `core.private_marketplace_groups`, `core.campaign_group_x_private_marketplace_deals`,
  `mntnselect_offering_versions`, `invoice_select_publisher_invoices`.

## Gotchas
- **Sparse override table (1 row).** Most advertisers are absent — never treat this as a complete
  per-advertiser margin map. Absence = "use the `select_margins` default," not "margin = 0."
- **SENSITIVE values.** Take rates are private; keep `budget_margin` / `data_margin` / `platform_fee` out of
  any shared artifact. Shareable cost work uses media/data_spend lenses only.
- **`NUMERIC(5,4)` fractions, not percents or dollars.** Don't multiply as if whole-number percents.
- **`update_time` is NULL until first update** — coalesce with `create_time` for a "last touched" timestamp.
- **Don't use `datastream_metadata.source_timestamp` as business time** — it is CDC-capture (ms epoch).
- **No `deleted`/`is_test`** on this dim — hygiene filtering must happen on the joined `advertisers` dim.

## Cost & partitioning notes
- **Physical is an unpartitioned, un-TTL'd CDC dimension** clustered on `select_advertiser_margin_id`;
  physical `numRows=1`, `numBytes=118`. There is **no partition column to filter** — clustering on the PK
  is the only prune lever, and it is irrelevant at this size.
- Cost figures (dry-run, 2026-07-19): **`SELECT *` (all 8 cols incl STRUCT) = 118 bytes upper bound**;
  **`SELECT advertiser_id` (1 narrow col) = 8 bytes**. Actual billed run floors at BigQuery's ~10 MB
  minimum (0.01 GB billed). This is a trivial-cost lookup — join it freely; the SELECT-* caveat is
  immaterial here.

## Example queries
```sql
-- Look up whether an advertiser has a Select override (schema/keys only — do NOT surface rate values in shared output)
SELECT select_advertiser_margin_id, advertiser_id, create_time, update_time
FROM `dw-main-silver`.core.select_advertiser_margins
WHERE advertiser_id = @advertiser_id;

-- Resolve advertiser Select margin = override-if-present-else-default (values stay internal)
SELECT a.advertiser_id
FROM `dw-main-silver`.core.advertisers a
LEFT JOIN `dw-main-silver`.core.select_advertiser_margins sam USING (advertiser_id)
WHERE a.deleted = FALSE AND a.is_test = FALSE;
```
