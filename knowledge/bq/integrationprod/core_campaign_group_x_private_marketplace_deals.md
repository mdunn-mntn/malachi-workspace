# integrationprod.core_campaign_group_x_private_marketplace_deals

## Purpose
Bridge (bronze Postgres-CDC dim via Datastream) that records **which private-marketplace (PMP) deal-group a campaign group buys inventory from**. Reach for it to tell whether a campaign group runs on PMP inventory at all, and which deal-group — the mechanism behind **MNTN Select** delivery and the PTV **Pause Ads** feature (both consume PMP inventory, per `data_knowledge`). The thin silver view `silver.core.campaign_group_x_private_marketplace_deals` is a `SELECT *` over this table. Rows begin at the MNTN Select launch era (~2025-07-31 per the silver-sibling analysis) — no pre-Select history.

## Grain & keys
- **Grain:** exactly one row per `campaign_group_id`. Verified 2026-07-29: 626 rows = 626 distinct `campaign_group_id` = 626 distinct (cg, deal-group) pairs. `campaign_group_id` is the effective primary key — a group attaches to **at most one** PMP deal-group.
- **Foreign keys:**
  - `campaign_group_id` → `campaign_groups.campaign_group_id` (1:1).
  - `private_marketplace_deal_group_id` → `private_marketplace_groups.private_marketplace_group_id` (N:1 — many campaign groups share one deal-group).

## Column meanings (only the non-obvious ones)
- **private_marketplace_deal_group_id** — despite the table name saying "…private_marketplace_deals", this column points at a PMP **deal-GROUP** (`private_marketplace_groups.private_marketplace_group_id`), i.e. a named bundle/level of deals, **not** an individual deal in `private_marketplace_deals`. Do not join it to `private_marketplace_deals` — you'll get zero matches.
- **create_time / update_time** — TIMESTAMP (UTC) of when the mapping row was created / last changed in the source Postgres.
- **datastream_metadata.source_timestamp** — CDC-capture epoch in **MILLISECONDS** (`= UNIX_MILLIS(update_time)`, family-wide convention). Datastream capture time, **not** business time — use `create_time`/`update_time`. `.uuid` = the CDC change-event id.

## Joins & relationships
- **→ `campaign_groups` on `campaign_group_id`** (partner grain 1 row per campaign group → **1:1, no fan-out**). The silver `campaign_groups` view carries `product_id` (1=PTV, 2=Select, 3=QuickFrame), budget, and status — join here to classify what kind of group owns the PMP attachment.
- **→ `private_marketplace_groups` on `private_marketplace_deal_group_id = private_marketplace_group_id`** (partner grain 1 row per deal-group; this bridge is the **N** side → joining FROM the bridge never fans out, but joining FROM `private_marketplace_groups` INTO the bridge fans out). Individual deals live in the deal-group's children (`private_marketplace_deals`, `private_marketplace_families`) — reach them via the deal-group, not directly from this bridge.

## Gotchas
- **No `deleted` / `is_test` columns** — the standard live-row filter cannot be applied here (columns absent). Treat every row as current CDC state; if you need "live" semantics, filter on the joined `campaign_groups` / `private_marketplace_groups`.
- **Naming trap:** table/column say "deal" but the FK targets a deal-**group** (see Column meanings).
- **Do NOT use PMP attachment as an MNTN-Select proxy.** Per `data_knowledge`, some PTV (`product_id=1`) groups also attach a PMP deal-group — those are **Pause Ads** campaigns (a separate PTV feature that consumes PMP inventory, not Select). To isolate Select, join `campaign_groups` and filter `product_id=2` (and exclude test-account advertisers).
- **May contain orphan rows** pointing at a `private_marketplace_deal_group_id` with no live `private_marketplace_groups` match (hard-deleted upstream) — use a LEFT JOIN if you need all bridge rows.

## Cost & partitioning notes
- **Genuine BASE TABLE**, non-partitioned, clustered by `campaign_group_id`, no TTL — `bq show`: 626 rows / 48,828 bytes. There is no partition filter to apply — the whole table is a single micro-scan; `SELECT *` bills the tier-1 minimum. When pulling a single group, filter on the clustered `campaign_group_id`.

## Example queries
```sql
-- All campaign groups on PMP inventory, classified by product line
SELECT b.campaign_group_id, b.private_marketplace_deal_group_id,
       cg.product_id,          -- 1=PTV(Pause Ads), 2=MNTN Select, 3=QuickFrame
       g.name AS deal_group_name
FROM `dw-main-bronze.integrationprod.core_campaign_group_x_private_marketplace_deals` b
LEFT JOIN `dw-main-silver.core.private_marketplace_groups` g
       ON g.private_marketplace_group_id = b.private_marketplace_deal_group_id
LEFT JOIN `dw-main-silver.core.campaign_groups` cg
       ON cg.campaign_group_id = b.campaign_group_id;
```
