# integrationprod.private_marketplace_deals

## Purpose
Reference dim for MNTN's **Private Marketplace (PMP) deals** — the negotiated/curated inventory deals MNTN buys on CTV exchanges (Magnite, Freewheel, Index Exchange, …). One row per deal holds the exchange-side deal ID, the floor CPM, the SSP/DSP partner, the flight window, and the `active` gate. Reach for it to (a) resolve a PMP deal name/ID (e.g. `WHERE lower(name) LIKE '%nba%'` for sports deals), (b) look up a deal's floor price / channel / partner, or (c) enumerate the live PMP set (`active = TRUE`). The `partner_deal_id` string references the exchange's own deal, but the config row (floor, budgets, active, name, owner) is maintained MNTN-side. DS42 (Select team) later converts PMP string IDs to integer `data_source_category_id` values downstream.

## Grain & keys
- **Grain:** one row per PMP deal — `private_marketplace_deal_id` PK, 1072 distinct = 1072 rows (verified). Every row is `channel_id = 8` (CTV): this table is CTV PMP inventory only, no display.
- **Key(s) / join columns:** `private_marketplace_deal_id` (internal PK) · `partner_deal_id` (exchange-side deal string, also 1:1 with the row). `advertiser_id` and `campaign_group_id` exist as columns but are **structurally NULL here** (0/1072 and 1/1072 populated) — the deal↔campaign-group mapping lives in the junction `core_campaign_group_x_private_marketplace_deals`, not on this table.

## Column meanings (only the non-obvious ones)
- **private_marketplace_deal_id** — internal MNTN PK; 1 per row.
- **partner_deal_id** — the **exchange/SSP-side deal string** the exchange knows the deal by; UUID or exchange code (e.g. `FUS-FUS-00718`, `WAR-1MP-01362`, `IXTVPDMNTNLGOO`). 1072 distinct = 1:1 with the row.
- **user_id** — internal **MNTN user** who owns/created the deal config (always populated, 1072/1072). NOT an advertiser or exchange partner.
- **audit_user_id** — internal MNTN user who last edited (always populated).
- **floor_price** — NUMERIC **CPM floor in USD** (observed 0 → 71.3); the deal's minimum clearing price. For `pricing_model = FIXED` this is the fixed price; for `BIDDABLE` it's the auction floor.
- **name** — human deal name. **Carries free-text lifecycle notes inside the string** ("(old, never live)", "(unused)", "(legacy)") — do not treat those as a status field; `active` is the real status.
- **active** — usable/enabled flag. 416 TRUE / 656 FALSE. **This is the liveness gate** — there is no `deleted`/`is_test` column on this table.
- **channel_id** — 8 = CTV for **every** row (uniform); PMP inventory here is CTV-only.
- **deal_type_id** — always `2` in this table (single value observed).
- **private_marketplace_level_id** — almost always `1` (1071/1072; one row = 3).
- **pricing_model** — `FIXED` (887) = fixed CPM at floor · `BIDDABLE` (119) = auction above floor · NULL (66).
- **partnership_deal_type** — `PUB_DIRECT` (664, publisher-direct) · `SSP` (166) · `EXCLUSIVE` (153) · NULL (89).
- **partner_id** — SSP/exchange partner code, 22 distinct (from deal names: 12=Magnite, 13=Freewheel, 19=Index Exchange; others uninferred).
- **dsp_partner_id** — DSP-integration code, only 3 distinct (8 dominant, 79, 2).
- **advertiser_id / campaign_group_id** — present but **structurally NULL** (0 and 1 of 1072). Do not use for advertiser/group linkage — see Joins.
- **publisher_id** — populated ~13% (136/1072); the publisher the deal is scoped to when set, else NULL.
- **private_marketplace_family_id** — populated 94/1072; groups related deals. Likely the deal-group layer the campaign-group junction keys on (unverified — see Joins).
- **min_budget / max_budget** — deal-level budget caps in USD; rarely set (14/1072 each).
- **start_time / end_time** — deal flight window (native TIMESTAMP). `end_time` NULL in 532/1072 rows = open-ended / evergreen.
- **create_time / update_time** — row audit timestamps (native TIMESTAMP; max update_time observed 2026-07-18). All four time columns are native TIMESTAMP — **no INT epoch columns**, so `time_unit = timestamp`; no epoch decoding needed.

## Joins & relationships
- **PK:** `private_marketplace_deal_id`.
- **Deal ↔ campaign_group** — do **NOT** join on this table's local `advertiser_id`/`campaign_group_id` (both essentially always NULL). The mapping lives in the junction **`core_campaign_group_x_private_marketplace_deals`** (silver `core.campaign_group_x_private_marketplace_deals`). That junction's columns are `campaign_group_id`, `private_marketplace_deal_group_id`, `create_time`, `update_time`, `datastream_metadata` — it keys on a **deal-GROUP id (`private_marketplace_deal_group_id`), not directly on `private_marketplace_deal_id`**. An intermediate grouping layer (likely `private_marketplace_family_id` / a `private_marketplace_groups` table) sits between deal and campaign_group. Grain: one row per (campaign_group × deal-group) → **M:N, expect fan-out**; dedup on the pair. Then `campaign_groups.campaign_group_id → advertisers.advertiser_id` for the advertiser.
- **channel_id = 8 → CTV** (channel dim). `partner_id` / `dsp_partner_id` are small-int exchange/DSP partner codes (no name column on this table).
- **Sibling mirror:** `core_private_marketplace_deals` (exposed as `silver.core.private_marketplace_deals`, data_catalog §core_private_marketplace_deals) is a near-duplicate mirror of the same Postgres PMP-deals table. This bare `integrationprod.private_marketplace_deals` carries **extra columns** not documented on the core mirror: `user_id`, `name`, `min_budget`, `max_budget`, `dsp_partner_id`, `audit_user_id`, `partnership_deal_type`, `private_marketplace_family_id`, `private_marketplace_level_id`.

## Gotchas
- **No `deleted` / `is_test` / `datastream_metadata` columns** on this table (unlike most integrationprod dims). Do NOT apply the usual `deleted=FALSE AND is_test=FALSE` filter — those columns don't exist. Use **`active = TRUE`** for the usable/live deal set (416 rows).
- **`advertiser_id` and `campaign_group_id` are essentially always NULL** (0/1072 and 1/1072). A deals→advertiser join on local columns returns nothing — use the junction (see Joins). Drift: data_catalog.md line 634 lists "core_private_marketplace_deals.campaign_group_id → campaign_groups" — that column is not populated on this bare table.
- **`name` embeds lifecycle text** ("(old, never live)", "(unused)", "(legacy)"); parse cautiously, don't infer status from the string — `active` is authoritative.
- **656/1072 rows are `active = FALSE`** (retired / never-live deals). Always filter `active = TRUE` for the live PMP set.
- **`channel_id` is uniformly 8 (CTV)** — no display PMP deals in this table; don't assume a channel breakdown exists.
- Prose (data_knowledge §"private_marketplace_deals Table") says the table "comes from Beeswax/exchanges" — refine: only `partner_deal_id` references the exchange; the config (floor, budgets, active, name, `user_id`/`audit_user_id`) is maintained MNTN-side.
- Tiny unpartitioned dim (~190 KB) — safe to full-scan; no date filter required (there is no date partition to filter on).

## Cost & partitioning notes
- **Genuine BASE TABLE** (`physical_table: self`), **no partition, no cluster, no TTL** — confirmed via `bq show` (timePartitioning None, clustering None, numRows 1072, numBytes 190,307). Not a SQLMesh view, so no stale-metadata caveat.
- **No partition column to filter.** The only pruning lever is column selection (dry-run, whole table): `SELECT *` (all 23 cols) = **190,307 B**; 3 narrow cols (`private_marketplace_deal_id, name, floor_price`) = **54,847 B**. Both trivial (<0.2 MB) — full scans are cheap.
- **"Always filter" analog:** filter **`active = TRUE`** to get the live set (416 rows); no date filter needed.

## Example queries
```sql
-- live PMP deals with their floor CPM and exchange partner
SELECT private_marketplace_deal_id, partner_deal_id, name, floor_price,
       pricing_model, partnership_deal_type, partner_id
FROM `dw-main-bronze.integrationprod.private_marketplace_deals`
WHERE active = TRUE
ORDER BY floor_price DESC;

-- resolve a deal by name (e.g. sports)
SELECT private_marketplace_deal_id, name, floor_price, active
FROM `dw-main-bronze.integrationprod.private_marketplace_deals`
WHERE lower(name) LIKE '%nba%';
```
