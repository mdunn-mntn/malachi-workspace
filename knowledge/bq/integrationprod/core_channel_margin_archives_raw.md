# integrationprod.core_channel_margin_archives_raw

## Purpose
Versioned edit history (bronze Postgres-CDC archive via Datastream) of the **global channel-level margin/pricing configuration** held live in `core_channel_margins_raw` (exposed as `silver.core.channel_margins`). Each time a channel×partner margin record is created or changed, a snapshot of the row is written here. Reach for it to reconstruct "what were the platform-default margin terms for channel C on partner P as-of date D?" or to trace margin-change timelines. This is the channel-grain member of the margin-archive family alongside `archives_advertiser_channel_margin_archives` (advertiser grain) and `archives_campaign_group_channel_margin_archives` (campaign-group grain). **SENSITIVE — margin values are private take-rate/pricing data; document schema/grain only, never surface the rate columns externally.**

## Grain & keys
- **Grain:** one row per **`channel_margin_archive_id`** — a point-in-time snapshot of one channel-margin record. Verified 2026-07-29: 88 rows = 88 distinct `channel_margin_archive_id`.
- **Primary key:** `channel_margin_archive_id` (surrogate; the sole cluster key).
- **Natural key is NOT reliable:** `(channel_margin_id, version)` yields only **69 distinct pairs across 88 rows** — the same (config, version) can appear more than once. Do **not** treat `(channel_margin_id, version)` as unique; order versions by `archive_time` and dedup on the surrogate id.
- **Coverage:** 8 distinct `channel_margin_id` (the 8 live channel×partner configs), channels {1,3,4,7,8}, partners {2,8,79}, `version` 1–38, `archive_time` 2020-03-03 → 2026-07-21.

## Column meanings (only the non-obvious ones)
- **channel_margin_archive_id** — surrogate PK of the archive *snapshot* (unique per row, cluster key). NOT the base-record id; do not join on this.
- **channel_margin_id** — FK to the base record in `core_channel_margins_raw` (silver `core.channel_margins`); the same value repeats across every version of that record. 8 distinct.
- **channel_id** — delivery channel the margin applies to. Observed domain {1, 3, 4, 7, 8} — 1 = display, 8 = CTV (workspace channel enum); 3/4/7 are additional/legacy channel ids that survive only in these global defaults (matches the live `channel_margins`).
- **partner_id** — the **DSP / bidding partner** the margin applies to. Observed domain {2 = Trade Desk, 8 = Beeswax, 79 = MNTN Bidder}. The partner axis is load-bearing — the same channel has different margin rows per DSP.
- **version** — per-`channel_margin_id` revision counter (1–38 observed). Tracks edit order within a record, but is **not table-wide unique with channel_margin_id** (see Grain) — prefer `archive_time` for as-of ordering.
- **create_time** — the base record's creation timestamp (copied from the base row; not the snapshot write time). Do not use it to order versions.
- **update_time** — the base record's last-modified time as captured in this snapshot.
- **archive_time** — when THIS snapshot row was written = the effective as-of moment for the version. Use this (or `version`) for as-of ordering.
- **budget_margin / budget_padding / partner_margin / data_margin** — NUMERIC(5,4) rate fractions (margin/padding shares). **partner_margin populated 85/88; the others populated.** **SENSITIVE — schema only, never document values.**
- **platform_fee / target_cpm / margin_reason_id / user_id** — present but **100% NULL in this channel-level archive** (0/88 each, 2026-07-29) — these columns are populated in the advertiser-level archive, not here. Do not rely on them.
- **datastream_metadata.source_timestamp** — Datastream CDC-capture epoch in **MILLISECONDS** (family-wide convention; ≈ `UNIX_MILLIS(archive_time)` for organically captured rows). NOT business time; earliest backfilled versions share one onboarding-snapshot value. `.uuid` = CDC change id.

## Joins & relationships
- **→ `core_channel_margins_raw` (silver `core.channel_margins`)** on `channel_margin_id`. Base grain = one row per (channel_id, partner_id) = current margin state (8 rows). Relationship archive:base = **N:1** (N historical versions per one live record). **Fan-out:** joining base→archive explodes to every version — dedup to latest with `QUALIFY ROW_NUMBER() OVER (PARTITION BY channel_margin_id ORDER BY archive_time DESC) = 1`.
- **`partner_id`** → `core.partners` (2=Trade Desk, 8=Beeswax, 79=MNTN Bidder). **`channel_id`** is a CTV(8)/display(1)/legacy(3,4,7) indicator, not a clean FK to a channel-margin dim.
- **Siblings:** `archives_advertiser_channel_margin_archives` (advertiser×channel history) and `archives_campaign_group_channel_margin_archives` (campaign-group×channel history) — same CDC-archive pattern at finer grains; advertiser/campaign-group margins override this channel-wide default.

## Gotchas
- **SENSITIVE margin table** — `budget_margin` / `budget_padding` / `partner_margin` / `data_margin` (and the always-NULL `platform_fee`/`target_cpm`) are pricing values; schema/grain only, never surface them externally.
- **`(channel_margin_id, version)` is NOT unique** (69 distinct pairs / 88 rows) — dedup on the surrogate `channel_margin_archive_id` and order by `archive_time`, not by `version`.
- **`platform_fee`, `target_cpm`, `margin_reason_id`, `user_id` are 100% NULL here** — do not read business meaning into them at the channel level.
- **No `deleted` / `is_test` columns** — the standard hygiene filter cannot be applied; this is an append-only archive of every version.
- **`create_time` is the base-record birth (constant across versions)** — do NOT order versions by it; use `archive_time`.
- **`datastream_metadata.source_timestamp` is ms CDC-capture, not business time** — the earliest backfilled versions share one onboarding-snapshot value.

## Cost & partitioning notes
- **Genuine BASE TABLE**, unpartitioned, clustered by `channel_margin_archive_id`, no TTL (archive retains history) — `bq show`: 88 rows / 15,264 bytes. No partition to prune; column pruning is the only lever and a full scan is negligible. **Avoid `SELECT *`** when you only need ids/timestamps — it drags in the SENSITIVE NUMERIC columns.

## Example queries
```sql
-- Latest margin snapshot per channel×partner config (non-sensitive cols only), as-of history
SELECT channel_margin_id, channel_id, partner_id, version, create_time, archive_time
FROM `dw-main-bronze.integrationprod.core_channel_margin_archives_raw`
QUALIFY ROW_NUMBER() OVER (
          PARTITION BY channel_margin_id
          ORDER BY archive_time DESC) = 1;
```
