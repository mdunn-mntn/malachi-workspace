# integrationprod.core_select_margins

## Purpose
Bronze CDC replica dimension holding the **global MNTN Select default margin / fee configuration** —
`budget_margin`, `data_margin`, `platform_fee` applied to Select advertisers that lack a per-advertiser
override in `core_select_advertiser_margins`. Each row is tagged with a `margin_source_id` (which pricing
source set it) and a `margin_reason_id`. This is the physical Postgres-CDC table behind the thin silver
view `dw-main-silver.core.select_margins` (`SELECT * FROM dw-main-bronze.integrationprod.core_select_margins`).
As of 2026-07-29 the table holds exactly **1 live row** (`select_margin_id=2`: budget_margin 0.75,
data_margin 0, platform_fee 0, `margin_source_id=2` = MSS).

## Grain & keys
- **Grain:** one row per Select global margin config (the active default). 1 row live 2026-07-29.
- **Primary key:** `select_margin_id` (INT64, surrogate; the physical is clustered on it).
- **Foreign keys:** `margin_source_id` → `integrationprod.core_margin_sources.margin_source_id` (1=DTR, 2=MSS, verified live); `margin_reason_id` → `integrationprod.core_margin_reasons.margin_reason_id` (NULL on the live row); `user_id` → the user who set it (NULL on the live row).
- **No `deleted` / `is_test` columns** — no live-row hygiene filter applies here.

## Column meanings (only the non-obvious ones)
- **`select_margin_id`** — surrogate PK, sole cluster key (live sample id = 2).
- **`budget_margin`** — NUMERIC margin rate as a fraction (live sample 0.75).
- **`data_margin`** — NUMERIC data-fee rate as a fraction (live sample 0). Zero on the live row.
- **`platform_fee`** — NUMERIC platform-fee rate as a fraction (live sample 0). Zero on the live row.
- **`margin_source_id`** — FK to `core_margin_sources`; live domain of that dim = `1=DTR`, `2=MSS`. The live row is `2` (MSS).
- **`margin_reason_id`** — FK to `core_margin_reasons` (nullable; NULL on the live row).
- **`user_id`** — who set the margin (nullable; NULL on the live row).
- **`create_time` / `update_time`** — Postgres business timestamps (create 2025-10-08, update 2026-05-20 on the live row).
- **`datastream_metadata`** — STRUCT<uuid STRING, source_timestamp INT64>; `source_timestamp` = millisecond CDC-capture epoch (not business time).

## Joins & relationships
- **`margin_source_id` → `core_margin_sources.margin_source_id`** — N:1 (1=DTR, 2=MSS).
- **`margin_reason_id` → `core_margin_reasons.margin_reason_id`** — N:1 (nullable).
- **Paired with `core_select_advertiser_margins`** — this is the global default; that table holds per-advertiser overrides. Resolution: advertiser override wins, else this global row. (Precedence is the natural reading of a default-vs-override pair; confirm against billing logic before operational use.)
- **History:** `integrationprod.archives_select_margin_archives` (`select_margin_archive_id`) holds change history for this config.

## Gotchas
- **Single-row global config** — this is not a per-advertiser table; it's the one active Select default. Per-advertiser variance lives in `core_select_advertiser_margins`.
- **Rates are fractions, not dollars** — `budget_margin`/`data_margin`/`platform_fee` are NUMERIC fractions.
- **`margin_reason_id` / `user_id` are NULL** on the live row — do not INNER-join through them.
- **No soft-delete columns.** No `deleted`/`is_test` — do not add those predicates (they will error).
- **`datastream_metadata.source_timestamp` is CDC-capture time in ms**, not business time.

## Cost & partitioning notes
- **BASE TABLE, physical `self`** (silver `core.select_margins` reads it directly). `bq show`: `type=TABLE`, `numRows=1`, `numBytes=126`, `timePartitioning=None`, `clustering.fields=[select_margin_id]`, no TTL.
- **Partition: none.** `require_partition_filter=false`. No cost trap.
- **Cost:** whole-table `SELECT *` dry-runs at ~0 GB (10 MB billed floor). Read freely.

## Example queries
