# integrationprod.core_private_marketplace_deals_x_private_marketplace_groups

## Purpose
Bridge table mapping **PMP deals to PMP groups** — the M:N link between `core_private_marketplace_deals` and `core_private_marketplace_groups`. A PMP group is a named bucket of deals (e.g. "CTV Direct Deals", "Disney/Hulu"); this junction records which deals belong to which groups. Reach for it to expand a group into its member deals, or to find every group a given deal is filed under.

## Grain & keys
- **Grain:** one row per (deal, group) pair. 1111 rows = 1111 distinct pairs (verified — no duplicate pairs).
- **Primary/natural key:** composite `(private_marketplace_deal_id, private_marketplace_group_id)`.
- **Foreign keys / join columns:** `private_marketplace_deal_id` → `core_private_marketplace_deals` (942 distinct here) · `private_marketplace_group_id` → `core_private_marketplace_groups` (143 distinct here).

## Column meanings (only the non-obvious ones)
- **private_marketplace_deal_id** — FK to the deal; cluster key #2.
- **private_marketplace_group_id** — FK to the group; cluster key #1 (leading key — filter by group to prune).
- **user_id** — internal MNTN user who created the mapping (not an advertiser).
- **create_time / update_time** — native TIMESTAMP (UTC) for the mapping row.
- **datastream_metadata.source_timestamp** — Datastream CDC snapshot epoch in **milliseconds**; replication time, not business time. `.uuid` = CDC event id.

## Joins & relationships
- **M:N bridge.** Both sides fan out: a deal belongs to **up to 7 groups** (observed max), a group holds many deals (1111 rows / 143 groups ≈ 8 deals/group avg). **Always dedup / aggregate before joining** into deal- or group-grain analyses.
- `private_marketplace_group_id` → `core_private_marketplace_groups.private_marketplace_group_id`.
- `private_marketplace_deal_id` → `core_private_marketplace_deals.private_marketplace_deal_id` (or sibling `integrationprod.private_marketplace_deals`).
- Distinct from `core_campaign_group_x_private_marketplace_deals` (which links deal-GROUPs to campaign groups) — this junction links deals to marketplace GROUPS, a different layer.

## Gotchas
- **Fan-out on both sides** — joining deals×groups directly multiplies rows; collapse to the grain you need first.
- **No `deleted` / `is_test` columns** — the standard live-row filter does not apply; every pair row is live.
- Not all deals/groups are covered here (942 of ~1073 deals, 143 of 146 groups) — LEFT JOIN and expect deals/groups with no mapping.
- `datastream_metadata.source_timestamp` is ms and reflects CDC replication, not the business `update_time`.

## Cost & partitioning notes
- **BASE TABLE**, no partition, no TTL; **clustered on `(private_marketplace_group_id, private_marketplace_deal_id)`** (numRows 1111, numBytes 86,658 via `bq show`). Filtering by `private_marketplace_group_id` (leading key) prunes blocks.
- **No partition column to filter.** Whole table <0.1 MB — full scans are free.

## Example queries
```sql
-- expand a PMP group into its member deals
SELECT g.name AS group_name, d.name AS deal_name, d.floor_price
FROM `dw-main-bronze.integrationprod.core_private_marketplace_deals_x_private_marketplace_groups` x
JOIN `dw-main-bronze.integrationprod.core_private_marketplace_groups` g
  ON x.private_marketplace_group_id = g.private_marketplace_group_id
JOIN `dw-main-bronze.integrationprod.core_private_marketplace_deals` d
  ON x.private_marketplace_deal_id = d.private_marketplace_deal_id
WHERE g.name = 'Disney/Hulu';
```
