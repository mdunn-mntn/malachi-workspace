# integrationprod.core_integration_margins

## Purpose
Datastream-CDC mirror of the **integration margin** table: the data margin MNTN applies to a *data-source
integration* (a third-party data provider MNTN integrates, keyed by `data_source_id`). Each row sets the
fractional margin taken on that data source's usage. Reach for it to read the current per-integration
data margin; for the full version history use the append-only sibling
`archives_integration_margin_archives`. This is a **commercially sensitive** margin table.

## Grain & keys
- **Grain:** one row per integration margin. **1 row** live (`integration_margin_id = 4`,
  `data_source_id = -1`).
- **Primary key:** `integration_margin_id` (surrogate INT, also the sole cluster key).
- **FKs:** `data_source_id` → `data_sources.id` (**`-1` = default/global**, i.e. applies to all/unknown
  data source); `margin_reason_id` → `core_margin_reasons.margin_reason_id` (NULL on the live row).

## Column meanings (only the non-obvious ones)
- **integration_margin_id** — surrogate PK (clustered; cosmetic on a 1-row table).
- **data_source_id** — the data-source integration this margin applies to → `data_sources.id`.
  **`-1` = default/global** (no specific data source; the live row uses -1).
- **data_margin** — the margin as a fraction, `NUMERIC(5,4)` (max 9.9999, 4 decimals). Live value
  `0.0025` = 0.25%. SENSITIVE.
- **margin_reason_id** — why the margin is set → `core_margin_reasons` (that lookup decodes -1=Unknown,
  1=MNTN AID adjustment, 2=MNTN Global adjustment, 3=MNTN CGID adjustment, 4=Advanced Pricing,
  5=Customer Incentive Program, …). **NULL on the live row.**
- **user_id** — app user who set the margin; NULL on the live row.
- **create_time / update_time** — business TIMESTAMP (UTC) from source Postgres.
- **datastream_metadata.source_timestamp** — INT64 **milliseconds** CDC-capture epoch (`TIMESTAMP_MILLIS`).

## Joins & relationships
- **`data_sources`** (dim): `data_source_id` → `data_sources.id` (`-1` sentinel = global).
- **`core_margin_reasons`** (dim): `margin_reason_id` → `core_margin_reasons.margin_reason_id`.
- **`archives_integration_margin_archives`** (append-only history): one row per
  `(integration_margin_id, version)` snapshot of this table — use it for point-in-time / change history.

## Gotchas
- **Only 1 live row** — this is a configuration table, not a fact table. Do not assume a rich domain.
- **`data_source_id = -1` is a sentinel** for default/global, not a real data source id.
- **`margin_reason_id` and `user_id` are NULL** on the live row — no reason/attribution captured.
- **No `deleted` / `is_test` columns** — the dataset-wide hygiene filter does not apply here.
- **SENSITIVE:** margin values are commercially sensitive; avoid pasting raw values into shared surfaces.
- **`source_timestamp` is ms CDC-capture, not business time** — use `create_time`/`update_time` for age.

## Cost & partitioning notes
- **BASE TABLE, physical `self`**, no partition, cluster=[integration_margin_id], no TTL. `bq show`:
  numRows=1, numBytes=94. Trivially below the billing floor. `SELECT *` freely.

## Example queries
```sql
-- Current integration data margins (whole table)
SELECT integration_margin_id, data_source_id, data_margin, margin_reason_id, update_time
FROM `dw-main-bronze.integrationprod.core_integration_margins`
ORDER BY integration_margin_id;
```
