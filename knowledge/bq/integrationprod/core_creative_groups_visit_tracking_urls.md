# integrationprod.core_creative_groups_visit_tracking_urls

## Purpose
Third-party **visit/conversion-tracking URLs** attached to a creative group — one row per configured URL that
fires on a tracked visit/landing event. The visit-side sibling of
`core_creative_groups_impression_tracking_urls`. Rarely used (only 2,189 rows across 2,157 groups). Child of
`core_creative_groups`; exposed as the `silver.core.creative_groups_visit_tracking_urls` VIEW.

## Grain & keys
- **Grain:** one row per **`visit_tracking_url_id`** — PK (rows 2,189 == distinct id, 2026-07-29).
- **Primary key:** `visit_tracking_url_id` (INT64); sole cluster key.
- **Foreign key:** `creative_group_id` → `core_creative_groups.group_id` — **N:1** (2,157 distinct groups →
  ~1.0 URLs per group). FK name is `creative_group_id`; parent PK is `group_id`.

## Column meanings (only the non-obvious ones)
- **`visit_tracking_url`** (STRING) — the URL/pixel that fires on a tracked visit/conversion event.
- **`is_post`** (BOOL) — HTTP method is POST (vs GET). **`request_body`** (STRING) — the POST body sent when
  `is_post=TRUE`.
- **`creative_group_id`** — FK to the parent group's `group_id` (name mismatch — see keys).
- **`create_time`** — TIMESTAMP the URL was configured; **no `update_time`** column.
- **No `server_side` column** — unlike the impression-tracking sibling, this table has no server_side flag.
- **`user_id`** — user who added the URL.
- **`datastream_metadata`** — Datastream CDC lineage RECORD; not business data.

## Joins & relationships
- **`creative_group_id` → `core_creative_groups.group_id`**: **N:1** — a group can have multiple visit-tracking
  URLs (1:N from the group). Aggregate before joining a group.
- The parent group's `override_visit_tracking` (BOOL) flag indicates the group uses its own visit-tracking
  URLs (these rows).
- **`silver.core.creative_groups_visit_tracking_urls`** is a VIEW over this table (verified 2026-07-29).

## Gotchas
- **FK name mismatch:** join `creative_group_id` → parent `group_id`.
- **No `server_side` column** here (present on the impression sibling) — do not reference it.
- **No `update_time`** — only `create_time`; use `datastream_metadata.source_timestamp` for later changes.
- **Very small / rarely populated** — only 2,157 groups have any visit-tracking URL; most creative groups
  have none.

## Cost & partitioning notes
- **No partition, no TTL** (child dim). 2,189 rows / ~0.5 MB; clustered on `visit_tracking_url_id`. Trivial
  cost — `SELECT *` bills the tier-1 minimum. `require_partition_filter: false`.

## Example queries
```sql
-- Visit-tracking URLs for a creative group
SELECT visit_tracking_url_id, visit_tracking_url, is_post
FROM `dw-main-bronze.integrationprod.core_creative_groups_visit_tracking_urls`
WHERE creative_group_id = @group_id;
```
