# integrationprod.core_select_advertiser_margins

## Purpose
Bronze CDC replica dimension holding **per-advertiser MNTN Select margin / fee overrides**. Each row sets
an advertiser-specific `budget_margin`, `data_margin`, and `platform_fee` that overrides the global Select
default in `core_select_margins` for that one advertiser. Reach for it to answer "does this advertiser
have a custom Select margin?" This is the physical Postgres-CDC table behind the thin silver view
`dw-main-silver.core.select_advertiser_margins` (`SELECT * FROM dw-main-bronze.integrationprod.core_select_advertiser_margins`).
As of 2026-07-29 the table holds exactly **1 live row** (advertiser `34331`: budget_margin 0.85, data_margin 0.025, platform_fee 0.05) — overrides are rare.

## Grain & keys
- **Grain:** one row per Select margin override, keyed to a single advertiser. Sparse — 1 row live 2026-07-29.
- **Primary key:** `select_advertiser_margin_id` (INT64, surrogate; the physical is clustered on it).
- **Foreign key:** `advertiser_id` → `integrationprod.advertisers.advertiser_id` (INT64). Expect at most one override row per advertiser.
- **No `deleted` / `is_test` columns** — no live-row hygiene filter applies here.

## Column meanings (only the non-obvious ones)
- **`select_advertiser_margin_id`** — surrogate PK, sole cluster key (live sample id = 5, not row-contiguous).
- **`advertiser_id`** — the advertiser this override applies to; FK to `advertisers`.
- **`budget_margin`** — NUMERIC margin rate as a fraction (live sample 0.85). Fraction/rate, not a dollar amount.
- **`data_margin`** — NUMERIC data-fee rate as a fraction (live sample 0.025).
- **`platform_fee`** — NUMERIC platform-fee rate as a fraction (live sample 0.05).
- **`create_time` / `update_time`** — Postgres business timestamps (`update_time` may be NULL on never-edited rows — it is NULL on the single live row).
- **`datastream_metadata`** — STRUCT<uuid STRING, source_timestamp INT64>; `source_timestamp` = millisecond CDC-capture epoch (not business time). Use `create_time`/`update_time` for business time.

## Joins & relationships
- **`advertiser_id` → `integrationprod.advertisers.advertiser_id`** — N:1 to the advertiser dim (apply `deleted=FALSE AND is_test=FALSE` on the advertiser side). At most one override row per advertiser, so no fan-out.
- **Pairs with `core_select_margins`** (the single global Select default). Resolution logic: an advertiser with a row here uses these rates; otherwise it falls back to the global `core_select_margins` default. (Fallback precedence is the natural reading of an override table; confirm against billing logic before relying on it operationally.)
- **History:** `integrationprod.archives_select_margin_archives` holds change history for the global Select margins.

## Gotchas
- **Effectively empty** — only 1 row live (2026-07-29). Do not assume every Select advertiser has a row; most inherit the global default in `core_select_margins`.
- **Rates are fractions, not dollars** — `budget_margin`/`data_margin`/`platform_fee` are NUMERIC fractions (0.85, 0.025, 0.05).
- **No soft-delete columns.** No `deleted`/`is_test` — do not add those predicates (they will error).
- **`update_time` can be NULL** (NULL on the single live row) — coalesce with `create_time` when ordering by recency.
- **`datastream_metadata.source_timestamp` is CDC-capture time in ms**, not business time.

## Cost & partitioning notes

## Example queries
```sql
-- resolve an advertiser's Select margin: override if present, else global default
SELECT a.advertiser_id, a.company_name,
       COALESCE(o.budget_margin, g.budget_margin) AS budget_margin,
       COALESCE(o.data_margin,  g.data_margin)    AS data_margin,
       COALESCE(o.platform_fee, g.platform_fee)   AS platform_fee
FROM `dw-main-silver.core.advertisers` a
LEFT JOIN `dw-main-silver.core.select_advertiser_margins` o USING (advertiser_id)
CROSS JOIN (SELECT budget_margin, data_margin, platform_fee
            FROM `dw-main-silver.core.select_margins` LIMIT 1) g
WHERE a.deleted = FALSE AND a.is_test = FALSE;
```
