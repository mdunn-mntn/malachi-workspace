# integrationprod.core_private_marketplace_levels

## Purpose
Tiny reference dim naming the **scope level** at which a PMP deal or group applies. 3 rows: `1=global`, `2=advertiser`, `3=campaign_group`. Reach for it to turn a `private_marketplace_level_id` on `core_private_marketplace_deals` / `core_private_marketplace_groups` into a scope label. A seed/lookup dim — join it, don't scan it.

## Grain & keys
- **Grain:** one row per PMP scope level. 3 rows (ids 1, 2, 3).
- **Primary/natural key:** `id` (PK, cluster key). `name` also unique.
- **Consumed as a FK target** by `private_marketplace_level_id` on `core_private_marketplace_deals` and `core_private_marketplace_groups`.

## Column meanings (only the non-obvious ones)
- **id** — PK, cluster key. Full domain = {1, 2, 3}.
- **name** — scope label: `1=global`, `2=advertiser`, `3=campaign_group`. This is the level at which a PMP deal/group is applied.
- **create_time / update_time** — native TIMESTAMP (UTC); all three rows seeded 2024-06-03.
- **datastream_metadata.source_timestamp** — Datastream CDC snapshot epoch in **milliseconds** (replication time). `.uuid` = CDC event id.

## Joins & relationships
- `core_private_marketplace_deals.private_marketplace_level_id` → `core_private_marketplace_levels.id` (deals observed at levels {1,3}).
- `core_private_marketplace_groups.private_marketplace_level_id` → `core_private_marketplace_levels.id` (groups uniformly level 1/global).
- 1:N FK target; this dim is the "1" side.

## Gotchas
- **No `deleted` / `is_test` columns** — the standard live-row filter does not apply; all 3 rows are live.
- The FK column on deals is named `private_marketplace_level_id` but the PK here is just `id` — join `deals.private_marketplace_level_id = levels.id`.
- `datastream_metadata.source_timestamp` is ms and reflects CDC replication, not the business `update_time`.
