# integrationprod.core_currency_codes

## Purpose
Static ISO-4217 **currency reference dimension** — one row per 3-character currency code, mapping the code
to its human name and a per-currency `billing_threshold`. Reach for it to decode a `currency` string into a
readable currency name, or to look up the billing threshold used per currency. 167 rows, effectively
constant. Datastream-CDC replica of the Postgres `core.currency_codes` app table.

## Grain & keys
- **Grain:** one row per ISO-4217 currency code. Static, 167 rows (verified 2026-07-29).
- **Primary / natural key:** `currency` (STRING, `maxLength=3` — the ISO-4217 alpha code, e.g. `USD`,
  `AUD`, `ARS`). Also the sole cluster key. There is no surrogate INT id.
- **Join column:** `currency` — the 1-side for any code→name/threshold decode.

## Column meanings (only the non-obvious ones)
- **`currency`** — ISO-4217 3-letter alpha code (`maxLength=3`); PK and cluster key.
- **`currency_name`** — the human currency name (e.g. `AUD` → `Australian Dollar`, `ARS` → `Argentine
  Peso`, `AFN` → `Afghani`).
- **`billing_threshold`** — per-currency billing-threshold value, **stored as a STRING of an integer** (e.g.
  `AUD` = `7000`, `ARS` = `80000`, `USD`/others vary). Cast before arithmetic. Value scale is per the source
  billing config; treat the raw string as the source of truth.
- **`datastream_metadata.source_timestamp`** — INT64 **milliseconds** CDC-capture epoch, not business time.

## Joins & relationships
- **1-side of a decode.** Join a table carrying a `currency` string onto this table on `currency` to attach
  the name / billing threshold — it cannot fan out (one row per code).

## Gotchas
- **PK is the string `currency`, not an INT** — join on the 3-char code, not a numeric id.
- **`billing_threshold` is a STRING** — cast to a number before comparing/summing; do not assume the numeric
  scale (it is the raw source billing config value).
- **No `deleted`/`is_test`/`create_time` columns** — the dataset-wide soft-delete dim filter does not apply;
  read all 167 rows.

## Cost & partitioning notes
- **Non-partitioned static dim: 167 rows / ~12 KB.** No partition, no TTL, `require_partition_filter=false`.
  Clustered on `currency` (a no-op at this size). `SELECT *` bills the 10 MB tier-1 minimum — broadcast-join
  it freely.

## Example queries
```sql
-- Decode a currency code
SELECT currency, currency_name, billing_threshold
FROM `dw-main-bronze.integrationprod.core_currency_codes`
WHERE currency = 'USD';

-- Full reference dump (~12 KB)
SELECT currency, currency_name, billing_threshold
FROM `dw-main-bronze.integrationprod.core_currency_codes`
ORDER BY currency;
```
