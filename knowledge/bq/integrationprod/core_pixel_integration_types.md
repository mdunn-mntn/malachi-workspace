# integrationprod.core_pixel_integration_types

## Purpose
Static reference enum that maps `pixel_integration_type_id` → the platform/method used to install an
advertiser's conversion pixel (e-commerce plugin, tag manager, manual, etc.). Reach for it to decode
`core_pixel_integrations.pixel_integration_type_id`. **8 rows, effectively constant.** Exposed as the
`silver.core.pixel_integration_types` view.

## Grain & keys
- **Grain:** one row per pixel integration platform. Static enum, 8 rows (verified 2026-07-29).
- **Primary key:** `pixel_integration_type_id` (INT, 1–8). Unique, no NULLs. Also the sole cluster key.
- **Join column:** `pixel_integration_type_id` — FK target for
  `core_pixel_integrations.pixel_integration_type_id`. Always the **1-side** of any join.

- **Types 2 (magento), 3 (prestashop), 5 (mntn-wordpress-plugin) exist in the enum but have 0 live
  integrations** — the enum lists a superset of currently-used platforms.
