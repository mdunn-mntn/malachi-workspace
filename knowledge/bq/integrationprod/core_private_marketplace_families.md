# integrationprod.core_private_marketplace_families

## Purpose
Small reference dim naming the **media families** (parent programmers / networks) that PMP deals are grouped under — 21 rows, one per family (Disney, Fox, NBC, Paramount (ViacomCBS), Warner Bros. Discovery, Samsung, Tubi, Sling, Fubo, DirecTV, Spectrum, …). Reach for it to turn a `private_marketplace_family_id` on a PMP deal into a human-readable programmer name. Join it, don't scan it.

## Grain & keys
- **Grain:** one row per media family. 21 rows (ids 1–21, contiguous).
- **Primary/natural key:** `private_marketplace_family_id` (PK, cluster key). `name` is also unique (one per family).
- **Consumed as a FK target** by `core_private_marketplace_deals.private_marketplace_family_id` (and the sibling `integrationprod.private_marketplace_deals`).

## Column meanings (only the non-obvious ones)
- **private_marketplace_family_id** — PK, cluster key. Contiguous 1–21.
- **name** — the media family / parent programmer label (e.g. `Disney`, `Fox`, `NBC`, `Paramount (ViacomCBS)`, `Warner Bros. Discovery`, `Hallmark Media (Crown Media)`). Some carry a parent-company clarifier in parentheses.
- **create_time / update_time** — native TIMESTAMP (UTC) row audit.
- **datastream_metadata.source_timestamp** — Datastream CDC snapshot epoch in **milliseconds** (replication time). `.uuid` = CDC event id.

## Joins & relationships
- `core_private_marketplace_deals.private_marketplace_family_id` → `core_private_marketplace_families.private_marketplace_family_id` (1:N; family = the "1" side). Only ~94 of ~1073 deals carry a family_id, so LEFT JOIN and expect NULLs.
- Not the same as `core_private_marketplace_groups` (operational deal buckets) — a family is the content-owner/programmer taxonomy; a group is a marketplace bucket.

## Gotchas
- **No `deleted` / `is_test` columns** — the standard live-row filter does not apply; all 21 rows are live.
- Most PMP deals have a NULL `private_marketplace_family_id` — do not assume every deal maps to a family.
- `datastream_metadata.source_timestamp` is ms and reflects CDC replication, not the business `update_time`.

## Cost & partitioning notes
- **BASE TABLE**, no partition, no TTL; clustered on `private_marketplace_family_id` (numRows 21, numBytes 1,697 via `bq show`). A broadcast/lookup dim — scan freely.
- **No partition column to filter.** Whole table <2 KB — effectively free.

## Example queries
```sql
-- the family taxonomy itself
SELECT private_marketplace_family_id, name
FROM `dw-main-bronze.integrationprod.core_private_marketplace_families`
ORDER BY private_marketplace_family_id;
```
