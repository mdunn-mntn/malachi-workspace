# integrationprod.mntnselect_order_items

## Purpose
Line-item detail of the MNTN Select order/booking system (Postgres CDC via Datastream). Each row is one
purchased line under an order header (`mntnselect_orders`): what offering version was bought, the sell
CPM (`target_cpm`) and media-buy CPM (`ad_buying_cpm`), the contracted impression volume, and an optional
targeting audience. Reach for it to reconstruct the commercial terms of a Select booking and to bridge a
Select order to the ad-serving entities (campaign groups) that fulfill it. Small, slowly-growing dim
(416 rows; earliest `create_time` 2025-07-31, the MNTN Select product launch date).

## Grain & keys
- **Grain:** one row per MNTN Select **order line item**. 416 rows = 416 distinct `order_item_id` (PK, clean).
- **Key(s) / join columns:** PK `order_item_id`. FKs: `order_id`→`mntnselect_orders` (N:1, 0 orphans),
  `offering_version_id`→`mntnselect_offering_versions` (N:1, 0 orphans), `advertiser_id`→`advertisers`,
  `audience_id`→audiences (nullable; that dim lives outside integrationprod). Bridge to ad-serving:
  `mntnselect_order_items_x_campaign_groups` (order_item_id ↔ campaign_group_id).

## Column meanings (only the non-obvious ones)
- **impressions** — the **contracted / ordered** impression volume for the line, not delivered actuals.
  Fractional because it is derived from a dollar budget: `impressions = budget / target_cpm * 1000`
  (verified: 272,727.27 × $55 CPM / 1000 = $15,000; 283,018.87 × $53 / 1000 = $15,000). Do not treat as
  a delivery metric.
- **target_cpm** — the CPM **sold to the advertiser** (sell side). **ad_buying_cpm** — the media-buy CPM
  MNTN **pays** (cost side). `target_cpm ≥ ad_buying_cpm` in every sampled row; the pair implies gross
  margin, so treat as **sensitive** — document meaning/grain, not a rate table. Both NUMERIC(12,2) dollars.
- **fulfillment_notify_status** — fulfillment-notification lifecycle. Domain (live counts):
  `not_notified` (380), `processing` (23), `notified` (13).
- **audience_id** — optional targeting audience for the line; NULL 276/416 (~66%).
- **prediction_id** — STRING UUID, NULL 373/416 (~90%); present when the line is linked to a
  delivery/pacing prediction. **pool_id** — STRING UUID, always populated; impression-pool identifier.
- **create_time / update_time / delete_time** — native TIMESTAMP (UTC). `delete_time` set ⇒ soft-deleted
  (20/416). There is **no `deleted` or `is_test` column** here; the live filter is `delete_time IS NULL`.
- **created_by / updated_by / deleted_by** — actor **user IDs**, but they do **not** resolve against
  `mntnselect_users` (388/416 orphan there) — they come from the broader platform user directory.
- **datastream_metadata.source_timestamp** — INT64 **milliseconds** CDC-capture epoch (`= UNIX_MILLIS(update_time)`
  within a few ms: e.g. 1784335010837 vs UNIX_MILLIS(update_time) 1784335010833). Datastream capture time,
  **not** business time — use `create_time`/`update_time` for business time. `datastream_metadata.uuid` = CDC event id.

## Joins & relationships
- **mntnselect_orders** (PK `order_id`, 1 row per order) — parent header. `order_item.order_id → orders.order_id`,
  **N:1** (319 distinct orders across 416 items; up to 7 items per order, avg ~1.3). 0 orphans. Joining is safe
  (grain stays at the item); do not COUNT items as orders.
- **mntnselect_offering_versions** (PK `offering_version_id`) — **N:1**, 0 orphans. The versioned offering/product
  config as-ordered.
- **mntnselect_order_items_x_campaign_groups** (junction, keys `order_item_id` + `campaign_group_id`) — bridge into
  ad-serving. **590 links / 309 distinct order_items ⇒ order_item : campaign_group is 1:N** (~1.9 CGs per linked item;
  107 items have no CG link yet). **Fan-out warning:** joining through this junction multiplies order-item rows by their
  campaign-group count — dedup or aggregate. Campaign groups with `product_id = 2` are MNTN Select.
- **advertisers** — `advertiser_id → advertisers` (**N:1**; advertiser PK is not literally `id` — key on the
  advertisers dim's advertiser id). Never NULL here.
- audiences dim — `audience_id` (nullable) references an audiences table outside integrationprod (not verifiable in-dataset).

## Gotchas
- **Soft-delete only:** no `deleted`/`is_test` columns — always add `delete_time IS NULL` for live rows (20/416 deleted).
- **`impressions` is contracted, not delivered:** it is budget ÷ `target_cpm` × 1000, hence fractional; never use it as an
  actuals/delivery number.
- **Margin exposure:** `target_cpm` (sell) minus `ad_buying_cpm` (buy) reveals gross margin — sensitive; share schema/grain, not rates.
- **`created_by`/`updated_by`/`deleted_by` don't join to `mntnselect_users`** (388/416 orphan) — platform user directory, not the Select users dim.
- **`source_timestamp` is ms Datastream capture time,** not business time.
- **Junction fan-out:** joining `mntnselect_order_items_x_campaign_groups` inflates row counts (1:N) — dedup first.

## Cost & partitioning notes
- **No partition** (real BASE TABLE, not a view); clustered on `order_item_id`. Tiny: 416 rows / 90,288 bytes total.
- **SELECT \* full scan = 90,288 bytes** (measured via `--dry_run`, all 18 columns / whole table). Column pruning barely
  matters at this size and there is no partition to prune, so no cost filter is required.
- **The one filter to always apply** is a correctness filter, not a cost one: `delete_time IS NULL` (live rows).

## Example queries
```sql
-- Live order line items with commercial terms (contracted impressions from budget/target_cpm)
SELECT oi.order_item_id, oi.order_id, oi.advertiser_id, oi.offering_version_id,
       oi.impressions AS contracted_impressions, oi.target_cpm, oi.ad_buying_cpm,
       oi.fulfillment_notify_status, oi.create_time
FROM `dw-main-bronze.integrationprod.mntnselect_order_items` oi
WHERE oi.delete_time IS NULL
ORDER BY oi.create_time DESC;

-- Bridge an order item to its ad-serving campaign groups (dedup the 1:N junction)
SELECT oi.order_item_id, ARRAY_AGG(DISTINCT j.campaign_group_id) AS campaign_group_ids
FROM `dw-main-bronze.integrationprod.mntnselect_order_items` oi
JOIN `dw-main-bronze.integrationprod.mntnselect_order_items_x_campaign_groups` j
  USING (order_item_id)
WHERE oi.delete_time IS NULL
GROUP BY oi.order_item_id;
```
