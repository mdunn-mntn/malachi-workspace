# integrationprod.core_media_plan_publishers

## Purpose
Datastream-CDC mirror of the **per-publisher lines of a media plan** — the normalized detail behind
`core_media_plan`. Each row is one recommended (or user-added) streaming publisher/network in a plan,
with its budget-split percentage, ranked position, badge, and an LLM `rationale`. Reach for it to read a
plan's publisher mix and budget allocation. `silver.core.media_plan_publishers` is a view over this base
table.

## Grain & keys
- **Grain:** one row per publisher line. 35,389 rows across 2,322 plans (~15.2 lines per plan; `rank`
  ranges 1–32).
- **Primary key:** `media_plan_publisher_id` (surrogate INT, also the sole cluster key).
- **FK:** `media_plan_id` → `core_media_plan.media_plan_id` (**the many side** — ~15 rows per plan).

## Column meanings (only the non-obvious ones)
- **media_plan_publisher_id** — surrogate PK (clustered).
- **publisher_ids** — JSON array of the underlying publisher id(s) this line maps to, e.g. `[263590]`,
  `[122]`. A non-network "Flex" budget line carries `[0]` (placeholder — reserved/flex budget, not a real
  publisher).
- **name** — publisher/network display name, e.g. "Roku Entertainment", "Peacock", "HBO Max", "Fox
  Sports", or the special **"Flex"** line (reserve budget for agile reallocation).
- **badge_state** — provenance/label of the line. Domain: `RECOMMENDED` (98%, system pick),
  `USER_ADDED` (human added a publisher), `USER_MODIFIED` (human edited a recommended line).
- **percentage** — the line's budget share as a percent, `NUMERIC(4,2)` (e.g. `10` = 10%, `6` = 6%).
- **rank** — display/priority order of the line within the plan (1 = top; up to 32).
- **rationale** — LLM-generated free-text justification for including the publisher.
- **is_manual** — TRUE = human-touched line; FALSE = system-generated. Correlates with (but is distinct
  from) `badge_state` — most USER_ADDED/USER_MODIFIED lines are `is_manual = TRUE`, but not all.
- **datastream_metadata.source_timestamp** — INT64 **milliseconds** CDC-capture epoch (`TIMESTAMP_MILLIS`),
  not business time.

## Joins & relationships
- **`core_media_plan`** (parent, N:1): `media_plan_id` → `core_media_plan.media_plan_id`. This table is
  the **many** side (~15:1) — a plan→publisher join fans the plan out; aggregate/window when rolling up.
- **`silver.core.media_plan_publishers`** is a VIEW over this base table.
- **Publisher decode:** `publisher_ids` elements reference publisher ids (see `public_publishers`); the
  `[0]` "Flex" placeholder does not decode to a real publisher.

## Gotchas
- **The parent PK is `media_plan_id`, not this table's PK** — join child→parent on `media_plan_id`; each
  plan has ~15 lines, so plan-level aggregates must `GROUP BY media_plan_id`.
- **"Flex" lines carry `publisher_ids = [0]`** — a reserve/flex budget bucket, not a targetable
  publisher; exclude when summing real publisher allocations.
- **`badge_state` and `is_manual` are related but not identical** — do not treat one as a proxy for the
  other.
- **No `deleted` / `is_test` columns** — the dataset-wide hygiene filter does not apply here.
- **`source_timestamp` is ms CDC-capture, not business time** — use `create_time`/`update_time` for age.

## Cost & partitioning notes
- **BASE TABLE, physical `self`**, no partition, cluster=[media_plan_publisher_id], no TTL. `bq show`:
  numRows=35,389, numBytes=9,806,139 (~9.4 MiB) — `rationale` free text + `publisher_ids` JSON dominate.
  `require_partition_filter: false`; nothing to prune. Project only the columns you need (skip `rationale`
  unless required) rather than `SELECT *`.

## Example queries
```sql
-- A plan's publisher mix and budget split (real publishers only)
SELECT rank, name, percentage, badge_state, is_manual
FROM `dw-main-bronze.integrationprod.core_media_plan_publishers`
WHERE media_plan_id = 2517
  AND name != 'Flex'
ORDER BY rank;

-- Line count + total allocated percent per plan
SELECT media_plan_id, COUNT(*) AS lines, SUM(percentage) AS total_pct
FROM `dw-main-bronze.integrationprod.core_media_plan_publishers`
GROUP BY media_plan_id;
```
