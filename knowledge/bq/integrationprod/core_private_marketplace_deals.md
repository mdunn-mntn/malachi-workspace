# integrationprod.core_private_marketplace_deals

## Purpose
Datastream-CDC bronze mirror of MNTN's **Private Marketplace (PMP) deals** dim — the negotiated/curated CTV inventory deals MNTN buys on exchanges (Magnite, Freewheel, Index Exchange, …). One row per deal holds the exchange-side deal ID, floor CPM, SSP/DSP partner, flight window, and the `active` gate. This is the `core_*` copy that carries `datastream_metadata` (CDC UUID + source_timestamp); `silver.core.private_marketplace_deals` is a view over it. A near-identical sibling **`integrationprod.private_marketplace_deals`** (1072 rows, no `datastream_metadata`) documents the same enum domains in detail. Reach for this to resolve a PMP deal name/ID, look up a deal's floor/channel/partner, or enumerate the live set (`active = TRUE`).

## Grain & keys
- **Grain:** one row per PMP deal — `private_marketplace_deal_id` PK, 1073 distinct = 1073 rows (verified). Every row is `channel_id = 8` (CTV): CTV PMP inventory only, no display.
- **Primary/natural key:** `private_marketplace_deal_id` (internal PK, also the cluster key) · `partner_deal_id` (exchange-side deal string, 1:1 with the row).
- **Foreign keys / join columns:** `private_marketplace_family_id` → `core_private_marketplace_families` (94/1073 populated) · `private_marketplace_level_id` → `core_private_marketplace_levels` (values {1,3}) · deal↔group mapping lives in the junction `core_private_marketplace_deals_x_private_marketplace_groups` (this table's local `advertiser_id`/`campaign_group_id` are structurally NULL — see Joins).

## Column meanings (only the non-obvious ones)
- **private_marketplace_deal_id** — internal MNTN PK; cluster key.
- **partner_deal_id** — the exchange/SSP-side deal string (UUID or exchange code, e.g. `FUS-FUS-00718`, `IXTVPDMNTNLGOO`); 1:1 with the row.
- **user_id / audit_user_id** — internal MNTN user who owns/created and who last edited the deal config (not advertiser or exchange partner).
- **floor_price** — NUMERIC CPM floor in USD; the deal's minimum clearing price.
- **name** — human deal name; embeds free-text lifecycle notes ("(old, never live)", "(unused)", "(legacy)") — `active` is the real status, not the string.
- **active** — the liveness gate: 411 TRUE / 662 FALSE. There is no `deleted`/`is_test` column, so filter `active = TRUE` for the usable set.
- **channel_id** — uniformly `8` (CTV) for every row.
- **pricing_model** — `FIXED` = fixed CPM at floor · `BIDDABLE` = auction above floor (both present).
- **partnership_deal_type** — `PUB_DIRECT` (publisher-direct) · `SSP` · `EXCLUSIVE` (all present).
- **advertiser_id / campaign_group_id** — present but structurally NULL (0/1073 and 1/1073). Do not use for advertiser/group linkage — see Joins.
- **private_marketplace_family_id** — → `core_private_marketplace_families` (media-family grouping); populated 94/1073.
- **private_marketplace_level_id** — → `core_private_marketplace_levels` (scope: 1=global, 3=campaign_group); values {1,3}, almost always 1.
- **publisher_id** — the publisher the deal is scoped to when set, else NULL.
- **min_budget / max_budget** — deal-level budget caps in USD; rarely set.
- **start_time / end_time / create_time / update_time** — native TIMESTAMP (UTC). `end_time` NULL = open-ended/evergreen.
- **datastream_metadata.source_timestamp** — Datastream CDC snapshot epoch in **milliseconds** (13-digit); reflects backfill/replication time, not the business `update_time`. `datastream_metadata.uuid` = CDC event id.

## Joins & relationships
- **PK:** `private_marketplace_deal_id`.
- **Deal ↔ group** — via junction `core_private_marketplace_deals_x_private_marketplace_groups` (M:N, up to 7 groups per deal); then group → `core_private_marketplace_groups`. Do NOT join on this table's local `advertiser_id`/`campaign_group_id` (structurally NULL).
- **`private_marketplace_family_id` → `core_private_marketplace_families.private_marketplace_family_id`** (media family, e.g. Disney/Fox/NBC).
- **`private_marketplace_level_id` → `core_private_marketplace_levels.id`** (scope level).
- **`channel_id = 8 → CTV`**. `partner_id` / `dsp_partner_id` are small-int exchange/DSP partner codes (no name column here).
- **Sibling `integrationprod.private_marketplace_deals`** (1072 rows) — same PMP-deals data minus `datastream_metadata`; see that doc for full enum-domain detail. `silver.core.private_marketplace_deals` is a view over THIS table.

## Gotchas
- **No `deleted` / `is_test` columns** — the standard `deleted=FALSE AND is_test=FALSE` filter does not apply. Use **`active = TRUE`** (411 live rows) for the usable deal set.
- **`advertiser_id` and `campaign_group_id` are essentially always NULL** — a deal→advertiser join on local columns returns nothing; use the group junction.
- **`channel_id` uniformly 8 (CTV)** — no display PMP deals here; don't assume a channel breakdown exists.
- **`name` embeds lifecycle text** — parse cautiously; `active` is authoritative.
- **`datastream_metadata.source_timestamp` is ms and reflects CDC replication**, not the business edit time — use `update_time` for business freshness.
- Tiny unpartitioned dim (~240 KB) — safe to full-scan; no date filter required.

## Cost & partitioning notes
- **BASE TABLE**, no partition, no TTL; **clustered on `private_marketplace_deal_id`** (numRows 1073, numBytes 239,903 via `bq show`). Filtering `private_marketplace_deal_id` prunes blocks, but the table is trivially small.
- **No partition column to filter.** The only real lever is column selection; the whole table is <0.25 MB — full scans are cheap.
- **"Always filter" analog:** filter `active = TRUE` for the live set.

## Example queries
```sql
-- live PMP deals with floor CPM, exchange partner, and media family
SELECT d.private_marketplace_deal_id, d.partner_deal_id, d.name, d.floor_price,
       d.pricing_model, d.partnership_deal_type, f.name AS family
FROM `dw-main-bronze.integrationprod.core_private_marketplace_deals` d
LEFT JOIN `dw-main-bronze.integrationprod.core_private_marketplace_families` f
  ON d.private_marketplace_family_id = f.private_marketplace_family_id
WHERE d.active = TRUE
ORDER BY d.floor_price DESC;
```
