# integrationprod.core_private_marketplace_groups

## Purpose
Dim of **PMP groups** — named buckets that organize PMP deals (e.g. "CTV Direct Deals", "Display Deals", "Disney/Hulu", "QPS Select Deals"). 146 rows, one per group. The many-to-many membership of deals in groups lives in `core_private_marketplace_deals_x_private_marketplace_groups`; this table holds each group's name plus its channel, scope level, DSP partner, and optional budget/threshold config. Reach for it to resolve a `private_marketplace_group_id` to a name or to filter groups by channel.

## Grain & keys
- **Grain:** one row per PMP group. 146 rows = 146 distinct `private_marketplace_group_id`.
- **Primary/natural key:** `private_marketplace_group_id` (PK, cluster key).
- **Foreign keys / join columns:** consumed by `core_private_marketplace_deals_x_private_marketplace_groups.private_marketplace_group_id` · `private_marketplace_level_id` → `core_private_marketplace_levels.id` (all rows = 1/global) · `channel_id` (channel dim) · `dsp_partner_id` (DSP partner code).

## Column meanings (only the non-obvious ones)
- **private_marketplace_group_id** — PK, cluster key.
- **name** — the group label; describes the bucket of deals (e.g. `CTV Direct Deals`, `Display Deals`, `Disney/Hulu`, `QPS Select Deals`, `Low Priority (INACTIVE)` — status hints appear in the string).
- **private_marketplace_group_type_id** — **100% NULL** across all 146 rows (unused).
- **channel_id** — domain observed = {8 (CTV), 1 (display), 3}; `8` dominant. `3` appears on an in-app-video-named group ("In-App Video Testing"). Channel convention: 8=CTV, 1=display (KB standard).
- **private_marketplace_level_id** — uniformly `1` (global) here → `core_private_marketplace_levels`.
- **advertiser_id / campaign_group_id** — present but **100% NULL** (0/146). Groups are not scoped to an advertiser/campaign-group at this layer.
- **dsp_partner_id** — DSP-integration partner code; populated 124/146.
- **partnership_deal_type** — `EXCLUSIVE` / `SSP` / `PUB_DIRECT` style string, sparsely set.
- **pmp_threshold_floor / pmp_threshold_ceiling** — integer threshold config; almost never set (floor 2/146, ceiling 0/146) — treat as effectively unused.
- **min_budget / max_budget / start_time / end_time** — optional group-level budget caps and flight window (native TIMESTAMP for the times).
- **datastream_metadata.source_timestamp** — Datastream CDC snapshot epoch in **milliseconds** (replication time). `.uuid` = CDC event id.

## Joins & relationships
- **PK:** `private_marketplace_group_id`, consumed by `core_private_marketplace_deals_x_private_marketplace_groups` (M:N — a group holds many deals, a deal joins up to 7 groups).
- `private_marketplace_level_id` → `core_private_marketplace_levels.id` (all 1/global here).
- `channel_id` → channel dim (8=CTV, 1=display).
- 143 of 146 groups appear in the deal junction — LEFT JOIN from group to junction and expect a few empty groups.

## Gotchas
- **`private_marketplace_group_type_id`, `advertiser_id`, `campaign_group_id` are 100% NULL** — do not use them as join keys or filters.
- **`pmp_threshold_floor`/`ceiling` are effectively unused** (floor 2/146, ceiling 0/146).
- **No `deleted` / `is_test` columns** — the standard live-row filter does not apply; status hints live inside `name` (e.g. "(INACTIVE)").
- `datastream_metadata.source_timestamp` is ms and reflects CDC replication, not the business `update_time`.

## Cost & partitioning notes
- **BASE TABLE**, no partition, no TTL; clustered on `private_marketplace_group_id` (numRows 146, numBytes 20,041 via `bq show`). Lookup dim — scan freely.
- **No partition column to filter.** Whole table ~20 KB — effectively free.

## Example queries
```sql
-- groups by channel, with member-deal counts
SELECT g.private_marketplace_group_id, g.name, g.channel_id, COUNT(x.private_marketplace_deal_id) n_deals
FROM `dw-main-bronze.integrationprod.core_private_marketplace_groups` g
LEFT JOIN `dw-main-bronze.integrationprod.core_private_marketplace_deals_x_private_marketplace_groups` x
  ON g.private_marketplace_group_id = x.private_marketplace_group_id
GROUP BY 1,2,3
ORDER BY n_deals DESC;
```
