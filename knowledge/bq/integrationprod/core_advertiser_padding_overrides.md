# integrationprod.core_advertiser_padding_overrides

## Purpose
Manual override table storing a per-advertiser `padding` value (a numeric multiplier, e.g. `"1.05"`).
Postgres CDC dim landed via Datastream. **Currently holds exactly 1 row** — it is an
exception/override table, not a per-advertiser default. Reach for it only to check whether a specific
advertiser has a padding override. Exposed as the `silver.core.advertiser_padding_overrides` view
(`SELECT * FROM` this table, verified 2026-07-29).

## Grain & keys
- **Grain:** one row per advertiser with a padding override. 1 row (verified 2026-07-29).
- **Primary key:** `advertiser_id` (sole cluster key).
- **Foreign key:** `advertiser_id` → `advertisers.advertiser_id`.

## Column meanings (only the non-obvious ones)
- **`padding`** — the override value, stored as a **STRING** even though it is numeric (the lone row is
  `"1.05"`). Cast before arithmetic.
- **`notes`** — free-text justification; the lone row references a ticket (`"PER-4384"`), i.e. these
  overrides are made deliberately with a paper trail.
- **`create_time` / `update_time`** — CDC write/update timestamps in source Postgres (lone row
  2025-05-09).
- **`datastream_metadata`** — Datastream CDC lineage RECORD; not business data.

## Joins & relationships
- **`advertiser_id` → `advertisers.advertiser_id`** — 1:0-or-1 optional lookup (almost every advertiser
  has no row). LEFT JOIN; expect NULL for essentially all advertisers.
- `silver.core.advertiser_padding_overrides` is a `SELECT *` view over this table.

## Gotchas
- **`padding` is a STRING** — cast to a number before using it as a multiplier.
- **Effectively empty (1 row)** — do not build logic that assumes broad coverage; a missing advertiser
  means "no override," not a default.
- **No `deleted`/`is_test` columns** — standard bronze soft-delete filter does not apply.

## Cost & partitioning notes
- **Non-partitioned dim: 1 row / ~86 bytes.** No partition, no TTL, no `require_partition_filter`.
  Clustered on `advertiser_id` (a no-op at this size).
- Full `SELECT *` bills the tier-1 10 MB minimum. Broadcast-join it freely.

## Example queries
```sql
-- Padding override for a given advertiser (NULL when none)
SELECT advertiser_id, SAFE_CAST(padding AS FLOAT64) AS padding, notes
FROM `dw-main-bronze.integrationprod.core_advertiser_padding_overrides`
WHERE advertiser_id = @advertiser_id;
```
