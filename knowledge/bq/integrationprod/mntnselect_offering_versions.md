# integrationprod.mntnselect_offering_versions

## Purpose
The MNTN Select **offering catalog**, versioned. A Select "offering" is a curated CTV inventory package (a
private-marketplace deal packaged for advertisers to buy in the Select marketplace). Every edit to an offering
publishes a **new immutable version row** here, so this table holds *every version of every offering* — its run
window, CPM rate card, impression cap, PMP-deal/group linkage, and editorial/featured listing metadata.
Reach for it when you need offering-level **pricing (CPM)**, **availability / run windows**, or to map an
offering to its **PMP deal / group**. It is the versioned child of `mntnselect_offerings` (one row per offering)
and a catalog/config table — **not** a delivery or spend table.

## Grain & keys
- **Grain:** one row per **offering version**. 895 rows across 160 offerings (~5.6 versions/offering).
- **Primary key:** `offering_version_id` — unique (895/895), clustered, sequence-like (increases with `create_time`).
- **Equivalent natural key:** `(offering_id, version_number)` — also unique (895/895). `version_number` is a
  0-based edit counter *within an offering*; 0 = initial draft (usually `is_published=false`), incrementing on
  each edit. The **latest published version per offering** = the current offering state.
- **Foreign keys:** `offering_id` → `mntnselect_offerings.offering_id`; `private_marketplace_group_id` →
  `core_private_marketplace_groups` (all 895 rows); `private_marketplace_deal_id` →
  `core_private_marketplace_deals` (331 rows only); `created_by`/`updated_by`/`deleted_by` → ops `users`/`mntnselect_users`.

## Column meanings (only the non-obvious ones)
- **offering_version_id** — surrogate PK; sequence-like, increases with `create_time`. The clustered column.
- **offering_id** — the offering this is a version of (FK to `mntnselect_offerings`). **Not unique** — one offering
  has many version rows.
- **version_number** — 0-based edit counter *within* an offering. 0 = initial draft (typically unpublished).
  Unique within `offering_id`. Increases with `create_time` here (unlike `archives_*` tables).
- **cpm** — **STRING, not numeric** — dollar CPM rate card for the offering, e.g. `"21.00"`. Observed $1–$71.30,
  59 distinct. `CAST(cpm AS FLOAT64)` to compute; text sort will misorder.
- **impressions** — INT64 inventory **impression cap/target** for the version — **NOT delivered impressions**.
  `1000000000` (1B) is the dominant value (263/895), used as an effectively-unlimited default; other values are
  real caps (e.g. 3,000,000 / 317,122,640). 97 distinct.
- **is_published** — whether this version is live/visible in the Select marketplace (705/895 true). The latest
  `true` version per offering is the current offering.
- **is_managed_sales** (134) — sold via managed/ops sales rather than self-serve.
- **is_request_inventory** (41) — uses the "request inventory" flow; `request_inventory_min_budget` is the dollar
  minimum-budget floor, NULL unless `is_request_inventory`.
- **flash_sale** (13) / **is_featured** (208) — offering-type / marketplace-listing flags.
- **ptv_vendor_name** — publisher/vendor label; populated on the **same 331 rows** that have
  `private_marketplace_deal_id` (PMP-deal-backed offerings) — the two co-occur.
- **private_marketplace_deal** (STRING label) / **private_marketplace_deal_id** (FK) — the linked PMP deal;
  populated on 331 rows, both NULL together on the other 564.
- **private_marketplace_group_id** — FK to `core_private_marketplace_groups`; populated on **all 895 rows**
  (every offering version belongs to a PMP group).
- **availability_start_time / availability_end_time** — window the offering is purchasable in the marketplace.
- **run_start_time / run_end_time** — window the inventory actually runs (distinct from availability).
- **create_time** — version-row write time (snapshot time); floor **2025-07-31** = Select launch. **delete_time /
  deleted_by** — soft-delete (0 rows deleted to date).
- **created_by / updated_by / deleted_by** — ops `user_id` of the actor (NOT advertiser id).
- **demographics / sales_sheet** — JSON blobs (targeting demo profile + sales-collateral spec).
- **cover_media_url / cover_image_attachment_id / featured_image_url / featured_image_attachment_id /
  featured_media_attachment_id / featured_overline / featured_tagline** — editorial/creative assets and marketing
  copy for the marketplace listing.
- **campaign_template_group_id** — FK to the campaign template group the offering seeds.
- **datastream_metadata.source_timestamp** — CDC-capture epoch in **MILLISECONDS**
  (`TIMESTAMP_MILLIS(1784553987672)` = `2026-07-20 13:26:27` = `create_time`). Not business time. `uuid` = CDC row id.

## Joins & relationships
- **`offering_id` → `mntnselect_offerings.offering_id`** — child→parent. `mntnselect_offerings` is 1 row/offering;
  joining offerings→versions **fans out 1:N** (~5.6 versions/offering). To get current state, pick `MAX(version_number)`
  (or the latest `is_published=true` version) per `offering_id` — do **not** join all versions.
- **`private_marketplace_group_id` → `core_private_marketplace_groups`** — N:1, no fan-out (all 895 rows have a group).
- **`private_marketplace_deal_id` → `core_private_marketplace_deals`** — N:1, only 331 rows populated; an inner join
  drops the 564 non-deal offerings.
- **To reach delivery/spend:** offering → PMP deal → `core_campaign_group_x_private_marketplace_deals` →
  `campaign_groups` (`product_id=2` = Select). That junction is many-to-many — fan-out on both sides; dedup first.
- **`created_by`/`updated_by` → ops `users` / `mntnselect_users.user_id`** (operator, not advertiser).

## Gotchas
- **Not a delivery table.** `impressions` is a catalog **cap** (1B = "unlimited" placeholder), and `cpm` is the rate
  card — neither is billed spend or delivered volume. For real Select delivery use `campaign_groups`
  (`product_id=2`) + spend/impression logs.
- **`cpm` is STRING** — `CAST(cpm AS FLOAT64)`; never sort/compare as text.
- **No `deleted` / `is_test` columns** — the standard `deleted=FALSE AND is_test=FALSE` dim filter does **not**
  apply here. Soft-delete is `delete_time IS NULL` (0 rows deleted today, so it is a no-op now, but filter defensively).
- **Versioned — naive joins double-count.** Always reduce to one version per offering (latest / published) before
  aggregating; there are ~5.6 versions per offering.
- **Every offering has a PMP *group* but not a PMP *deal*.** `private_marketplace_group_id` is populated on all 895
  rows; `private_marketplace_deal_id` / `private_marketplace_deal` on only 331. Don't assume a deal exists.
- **`create_time` floor 2025-07-31** = MNTN Select launch; no offering history before that date.

## Cost & partitioning notes
- Tiny CDC dim: physical BASE TABLE, **no time partition**, clustered on `offering_version_id`, ~895 rows.
- **Full-table `SELECT *` dry-run = 1,008,143 bytes (~1.0 MB)** — equals `bq show` `numBytes`, i.e. the whole table
  (nothing to prune; unpartitioned). Cost is negligible; no partition filter is needed or possible.
- The "always-apply" filter here is a **correctness** filter, not a cost one: `is_published = TRUE AND delete_time
  IS NULL`, then dedup to the latest `version_number` per `offering_id` to get current live offerings.
- Cluster on `offering_version_id` only speeds point-lookups by version id.

## Example queries
```sql
-- Current live offering catalog (latest published version per offering) with numeric CPM
WITH ranked AS (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY offering_id ORDER BY version_number DESC) AS rn
  FROM `dw-main-bronze.integrationprod.mntnselect_offering_versions`
  WHERE is_published AND delete_time IS NULL
)
SELECT offering_id, name, CAST(cpm AS FLOAT64) AS cpm_usd, impressions,
       private_marketplace_deal_id, ptv_vendor_name, run_start_time, run_end_time
FROM ranked WHERE rn = 1
ORDER BY cpm_usd DESC;
```
