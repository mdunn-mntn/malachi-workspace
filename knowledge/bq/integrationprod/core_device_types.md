# integrationprod.core_device_types

## Purpose
Static reference enum decoding `device_type_id` into a device-type label and rolling each device type up to
its family via `device_type_group_id`. Reach for it to name a `device_type_id` (MOBILE, PHONE, PC,
CONNECTED_TV, SET_TOP_BOX, GAMES_CONSOLE, TABLET, ...) and to group device types into families. Child of
`core_device_type_groups`. Datastream-CDC replica of Postgres `core.device_types`.

## Grain & keys
- **Grain:** one row per device type. Static enum, 9 rows (full dump verified 2026-07-29).
- **Primary key:** `device_type_id` (INT, sole cluster key). Includes sentinel `-1` (UNKNOWN).
- **Foreign key:** `device_type_group_id` → `core_device_type_groups.device_type_group_id` (N:1).

- **`device_type_group_id`** — FK to `core_device_type_groups`; 4 CTV-family devices (4–7) roll into group 3.
- **`datastream_metadata.source_timestamp`** — INT64 **milliseconds** CDC-capture epoch, not business time.

## Joins & relationships
- **Child of `core_device_type_groups`:** `device_type_group_id` → that table (N:1); this table is the
  1-side for any `device_type_id` decode (cannot fan out).
- **Not the same as `integrationprod.device_type`** (device_type.md) — that is a separate flat 8-row
  INT→name ENUM (ids 1–8, no group, no `-1`) used to decode the INT `device_type` on `bronze.raw` bidder
  event tables. Pick the enum that matches the column you hold.

## Gotchas
- **Sentinel `-1` = UNKNOWN** — filter out when enumerating real device types.
- **Two mobile devices** (1 MOBILE, 2 PHONE) both roll to group 1; **four devices** (4–7) roll to CTV group 3.
- **No `deleted`/`is_test` columns** — the soft-delete dim filter does not apply; read all 9 rows.
- **Do not confuse with `integrationprod.device_type`** (different table, different id set) — see Joins.

## Cost & partitioning notes
- **Non-partitioned static dim: 9 rows / ~654 bytes.** No partition, no TTL, `require_partition_filter=false`.
  Clustered on `device_type_id` (a no-op at this size). `SELECT *` bills the 10 MB tier-1 minimum.

## Example queries
```sql
-- Decode device types + their family
SELECT dt.device_type_id, dt.device_type_name, g.device_type_group_name
FROM `dw-main-bronze.integrationprod.core_device_types` dt
JOIN `dw-main-bronze.integrationprod.core_device_type_groups` g USING (device_type_group_id)
ORDER BY dt.device_type_id;
```
